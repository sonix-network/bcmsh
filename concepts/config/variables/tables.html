Forwarding tables and routing

Sizes of the shared hash and TCAM tables (L2, host, exact match, ALPM/LPM), ECMP, VXLAN/RIOT overlay resources, hashing and learning. See Forwarding table sizes.

Set in several SONiC Trident 3 HWSKU files: arl_clean_timeout_usec, bcm_tunnel_term_compatible_mode, flow_init_mode, fpem_mem_entries, host_as_route_disable, ipv6_lpm_128b_enable, l2_entry_used_as_my_station, l2_mem_entries, l2xmsg_hostbuf_size, l2xmsg_mode, l3_alpm_enable, l3_alpm_ipv6_128b_bkt_rsvd, l3_ecmp_levels, l3_max_ecmp_mode, l3_mem_entries, lpm_scaling_enable, max_vp_lags, mpls_mem_entries, multicast_l2_range, multicast_l3_range, riot_enable, riot_overlay_ecmp_resilient_hash_size, riot_overlay_l3_egress_mem_size, riot_overlay_l3_intf_mem_size, use_all_splithorizon_groups, vlan_xlate_1_mem_entries, vlan_xlate_2_mem_entries.

l2x_bulk_op_learn_pause
Type:
number
Default:
0

This soc property is applicable in L2 FIFO mode (l2xmsg_mode = 1), it is used to pause L2 learning during L2 bulk operations having record to L2 FIFO enabled. This soc property can be used in cases where there is very high L2 churn, which may cause contention for L2 FIFO table during L2 bulk operation, causing L2 bulk operation to timeout.
