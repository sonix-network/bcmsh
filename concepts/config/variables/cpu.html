CPU, DMA, interrupts and counters

How the SDK talks to the chip over PCIe: packet and table DMA, S-channel, interrupts, counter collection and CPU threads.

Set in several SONiC Trident 3 HWSKU files: bcm_stat_flags, bcm_stat_interval, bcm_stat_jumbo, cdma_timeout_usec, ctr_evict_enable, dma_desc_timeout_usec, miim_intr_enable, pdma_descriptor_prefetch_enable, pktdma_poll_mode_channel_bitmap, schan_intr_enable, tdma_intr_enable, tdma_timeout_usec, tslam_timeout_usec.

bcm_esw_pscan_thread_pri
Type:
number

Specifies the priority of the bcmPSCAN thread

bcm_rx_thread_pri
Type:
number

Specifies the priority of the BCM RX thread

bcm_stat_flags
Type:
number

Flag values to be ORd together: 0x0 indicates that counter DMA should NOT be used 0x1 indicates that counter DMA should be used (default).

SONiC:

set in 10 Trident 3 HWSKU files; 1, 0

bcm_stat_interval
Type:
number

Set stat collection interval in microseconds. Setting this to 0 will prevent counters from being started.

SONiC:

set in 16 Trident 3 HWSKU files; 2000000, 1000000

bcm_stat_jumbo
Type:
number
Default:
1518

Threshold value for oversize (*OVR) frame size. Values over 1518 affect the *OVR statistics computation

SONiC:

set in 9 Trident 3 HWSKU files; 9236

0

BCM Statistics Collection: Set bitmap of ports on which stat collection will be enabled. Default is all ports.

bcm_stat_sync_timeout
Type:
number

Timeout delay in microseconds before bcm_stat_sync returns BCM_E_TIMEOUT

bcm_tx_queue_size
Type:
number

Specifies the maximum number of packets which can start to allocate resources and transmit. Depending on the Tx resources, an appropriate value can get better performance. The range of suggested values is 64 to 512. If fewer than 10 threads may transmit simultaneously, this parameter can be left at the default value of 0.

counter_collection_preempt_enable
Type:
number

Enable the counter collection preemption. Current counter collection will be preempted when the following APIs are active: - bcm_stat_sync_multi_get - bcm_stat_sync_multi_get32 Valid values: 0: Disable 1: Enable

counter_collection_preempt_max_period_usec
Type:
number

The maximum time period in microseconds for counter collection preemption. When continous preemption time exceeds this maximum period, the preemption will be paused to allow a full counter collection completes Valid values: 0: No maximum period 1 ~ (2^31-1): 1 ~ 2,147,483,647 microseconds Note if this value is non-zero but less than current counter collection interval, the maximum preempt time period will be current counter collection interval,

irq_adaptive_poll_mode
Type:
number

Adaptive IRQ poll mode. In case lot of interrupts are happening, interrupt thread switches to interrupt poll mode and switch back to kernel mode to wait for interrupt only when no interrupt status is pending. This feature is specific to cmicx based devices. Adaptive IRQ poll mode is enabled by default. It can be disabled by setting the configuration property to be 0.

mdio_output_delay

Forms:

mdio_output_delay_<N>

pcie_flash_mem_params
Type:
number

Parameter of the QSPI flash memory used to hold the PCIe firmware If the value is not empty, should specify the parameters of the flash memory: <ID>,<sector size>,<page size> ID: The one byte manufacturer ID of the flash chip. The rest of the parameters will be applied only if the read ID is equal to this one. sector size in bytes: The smallest part of the chip that can be erased, should be a multiple of the page size. page size in bytes: smallest access unit.

pdma_descriptor_prefetch_enable
Type:
number

Enable support for packet DMA descriptor prefetch mode. This feature enables descriptors contiguous in memory to be prefetched and thus increase packet dma throughput. This feature is specific to cmicx based devices.

SONiC:

set in 10 Trident 3 HWSKU files; 1

pdma_dv_free_count
Type:
number

This soc property defines the number of free DMA Vectors the SOC DMA driver will cache to avoid calling alloc/free routines The value can vary between 32 to 512.

pdma_dv_free_size
Type:
number

This soc property defines the number of DCBs(dma control blocks) in the DMA vector. the value can vary between 160 to 640. This value has to be greater than pdma_dv_free_count property User has to make sure that enough memory is available to allocate these DCBs.

pdma_max_err_count

pktdma_poll_mode_channel_bitmap
Type:
number

This soc property indicates a channel bitmap which uses packet dma poll mode. Bit n is for channel n. The bit value 1 means poll mode, 0 means interrupt mode. Default value is 0x0. Example: pktdma_poll_mode_channel_bitmap=0x02 means channel 1 uses poll mode.

SONiC:

set in 8 Trident 3 HWSKU files; 1

0

Select packet I/O driver by specifying driver type. Value: 0: classic (default type). Use bcm_tx/bcm_rx API set. 1: streamlined. Use bcm_pktio API set. Valid only for devices that support streamlined packet I/O driver.

number

Indicate reserved RDBGC counters. reserved_rdbgc_x controls RDBGCx. By default RDBGC1-2 are reserved. 0 – Unreserve the RDBGC counter. 1 – Reserve the RDBGC counter.
