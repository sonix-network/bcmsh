ACL, field processor and UDF

Field processor (ACL) behaviour and the UDF extraction resources reserved for protocols.

Set in several SONiC Trident 3 HWSKU files: ifp_inports_support_enable.

bcm_meter_control_ifg_only_adjust
Type:
number

When enabled, it will modify only metering IFG (inter frame gap), when using switch control - bcmSwitchMeterAdjust in API bcm_switch_control_set and bcm_switch_control_get. Valid Values: 0 - disable; 1 - enable.

bcm_rate_<type>_index
Type:
number

Storm-control meter index used for one packet type (bcast, mcast, dlf, unknown_mcast).

Names:

bcm_rate_bcast_index, bcm_rate_dlf_index, bcm_rate_mcast_index, bcm_rate_unknown_mcast_index

field_atomic_update
Type:
number

Update field processor entries atomically (no traffic hit while an entry changes), at the cost of a spare slice.

field_presel_prio_mode
Type:
number
fp_even_index_for_ingress_flow_meter
Type:
number

Enable or Disable allocating even based meter indexes for flow mode metering for stage ingress. 0=Disable, 1=Enable.

fp_qual_ipv6_ipv4_overlay_enable
Type:
number

Property to select overlay qualifiers for source and destination IPv4 and v6 qualifiers during group create. This enables the qualifiers (srcIp6, srcIp) or (dstIp6, dstIp) be part of same field selectors that helps in reducing the size of the TCAM width and might reduce the group mode from double-wide to single-wide.

gbp_disable
Type:
number
Default:
0

Disable vxlan gbp Feature

global_meter_control
Type:
number
Default:
1

Enable Service Meter

gpe_ioam_disable
Type:
number
Default:
0

Disable GPE IOAM Feature

ifp_inports_support_enable
Type:
number
Default:
0

Allow the ingress field processor to qualify on a set of input ports (InPorts). Set to 1 in SONiC files; SONiC ACL tables bound to several ports need it.

SONiC:

set in 49 Trident 3 HWSKU files; 1

On Seastone2:

ifp_inports_support_enable=1

ifp_lookup_depth
Type:
number

Configures depth of each IFP lookup for UTT devices Lookup specfic value can be specified using suffix “_#”. This is an optional parameter. Default value is chip specific.

Forms:

ifp_lookup_depth_<N>

ifp_mem_size
Type:
number

Configures size of IFP memory for UTT devices Default size is chip specific.

ifp_num_lookups
Type:
number

Configures number of IFP lookup for UTT devices Default value is chip specific.
