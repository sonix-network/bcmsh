Variable reference

Every configuration variable that the SONiC Trident 3 SAI and SDK read, 901 in all, grouped by area. Each entry gives the type, the default where it is known, the name forms the lookup accepts (see Names, scopes and precedence), how often the variable is set in SONiC’s Trident 3 HWSKU files, and its value on a Celestica Seastone2 running SONiC.

Every variable is also listed in the Index.
