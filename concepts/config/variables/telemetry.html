Telemetry, timing and OAM

Flow tracker, IFA, QCM, BFD and PTP/BroadSync. Most of these need matching embedded-application firmware; setting a variable alone does not enable a feature.

Set in several SONiC Trident 3 HWSKU files: ptp_bs_fref, ptp_ts_pll_fref.

appl_param_e2e_scheme_cos
Type:
number
Default:
8
bfd_control_plane_independence
Type:
number
Default:
1

If the config property is enabled by default (set to 1), if bfd_control_plane_independence is 0, Fw transmit BFD packets with C bit 0, otherwise C bit 1. The default value of the config property is 1 (enabled)

bfd_cosq
Type:
number
Default:
0

BFD CoS queue

bfd_dip_lookup_enable
Type:
number
Default:
0

When enabled, destination IP address(DIP) along with source IP address(SIP) is used to de-multiplex BFD session for zero Your-discriminator packets. 0 – Only SIP for de-multiplex BFD session. 1 – SIP and DIP both for de-multiplex BFD session. 2 – Only DIP for de-multiplex BFD session.

bfd_enable
Type:
number
Default:
0

Enable BFD features

bfd_encap_memory_size
Type:
number
Default:
0

Memory allocated for BFD encapsulation data (in bytes)

bfd_feature_enable
Type:
number

Enable BFD Feature with bit map fields, lower bits will take precedence, 1st LSB bit is Multi Hop as default, 2nd LSB bit is Micro/Trunk and 3rd LSB bit is Echo mode Feature. Value 0 will disable all the features.

bfd_ifp_lookup_enable
Type:
number
Default:
0

When this property is configured, IFP will be used for bfd look up instead of HW tables look up. The default value of the config property is 0

bfd_ignore_l3_host_config
Type:
number
bfd_jitter_disable
Type:
number
bfd_l3_iif_to_vrf_map_enable
Type:
number
Default:
0

Enable/Disable L3IIF to VRF lookup in the FW.

bfd_num_sessions
Type:
number
Default:
256

Number of BFD sessions

bfd_over_vxlan_zero_discr_demux
Type:
number
Default:
0

De-multiplex BFDoVxLAN session for zero Your-discriminator packets. 0 – Only VNID for de-multiplex BFD session. 1 – VNID + VTEP SIP both for de-multiplex BFD session.

bfd_pkt_tx_on_state_change
Type:
number
bfd_remote_discriminator
Type:
number
Default:
0

If the config property is enabled (set to 1), configuring remote discriminator value is always same, not overriding with the learned BFD My discriminator value. The default value of the config property is 0 (disabled)

bfd_remote_discriminator_reset
Type:
number
Default:
0

Enable/Disable the configuration of resetting remote discriminator variable under certain circumstances such as receiving admin_down or down messages when local session state is UP. The default value of the config property is 0 (disabled)

bfd_session_down_event_on_create
Type:
number
Default:
0

If this config property is enabled (set to 1), there would be a state change event (State would be down for the endpoint) received after the session is created if we do not receive any packets from the peer within detection_multiplier * 1 seconds. Default value is 0 (disabled)

bfd_sha1_keys

bfd_simple_password_keys

number

Number of BFD simple password authentication keys

bfd_thread_pri
Type:
number

Specifies the priority of the bcmBFD thread

bfd_trunk_auto_tx_port_update_disable
Type:
number
Default:
0

Enable/Disable of updating TX port with RX port behavior of BFD over Trunk endpoints.

bfd_tx_raw_ingress_enable
Type:
number
Default:
0

Enable/Disable of raw ingress inject of BFD Tx packets from BTE for all sessions which includes support for BFD over LAG, ECMP and except micro, echo BFD

bfd_use_endpoint_id_as_discriminator
Type:
number
Default:
0

Enable/Disable the configuration of using endpoint index itself as local discriminator for BFD endpoints.If the config property is enabled (set to 1), any value passed in local_discriminator field in endpoint info will be ignored and endpoint index would be used instead. The default value of the config property is 0 (disabled)

flowtracker_flex_state_transition_mode
Type:
number
Default:
0

Specify mode for flexible state transition in flowtracker. 0 – State transition table is pre-defined at SDK initialization. It cannot be modified using APIs after SDK initialization (default). 1 – State transition table is pre-defined at SDK initialization. It can be modified using APIs after SDK initialization. 2 – State transition table is not pre-defined at SDK initialization.

macsec_enable
Type:
number
Default:
0

Specifies to enable or disable MACSEC feature on the specified port. MACSEC feature might be provided by a PHY device attached to switch port. (Default is to disable MACSEC)

Forms:

macsec_enable_<port>, macsec_enable_<type>, macsec_enable

mcs_hostmem_size
Type:
number

In supported devices, Part of Host Memory can be allocated and provided to the uC for its internal usage This variable specifies Size in KB. Suffix with _uc0 _uc1 etc.

mcs_uart_bmp
Type:
number

Config to override the default UART number used by the uKernel console User needs to provide the new UART number as a bitmap. i.e bit-0 is UART0 etc. If the config property is set to 0, or if more than one bit is set, firmware will use the default UART. Suffix this config with _uc0 _uc1 etc.

ptp_bs_ka, ptp_bs_ki, ptp_bs_kp, ptp_bs_mndiv, ptp_bs_ndiv_int, ptp_bs_pdiv, ptp_bs_vco_div2, ptp_ts_ka, ptp_ts_ki, ptp_ts_kp, ptp_ts_pll_mndiv, ptp_ts_pll_n, ptp_ts_pll_pdiv
