Chip, boot, warm boot and diagnostics

Clocks, the Cancun/flex package, memory caching and scanning (soft-error protection), warm-boot storage, module start-up and diag-shell behaviour.

Set in several SONiC Trident 3 HWSKU files: cancun_dir, core_clock_frequency, disable_pcie_firmware_check, dpp_clock_ratio, help_cli_enable, mem_cache_enable, mem_scan_enable, memlist_enable, os, parity_correction, parity_enable, reglist_enable, scache_filename, skip_L2_USER_ENTRY, sram_scan_enable, stable_location, stable_size, table_dma_enable, warmboot_knet_shutdown_mode.

egr_share_flex_counter_pool
Type:
string

Specifies egress objects sharing same pool or using exclusive pool. Example: egr_share_flex_counter_pool=split(vlan,vfi) make egr_vlan, egr_vfi use exclusive pool. egr_share_flex_counter_pool=share(vlan,vfi) make egr_vlan, egr_vfi use same pool. An object can appear in both share case and split case, but in each case it can appear one time at most. Use token between each groups and use comma between each objects. eg: egr_share_flex_counter_pool=split(A,B,C);share(C,D); Some objects may use the same HW table, so only the first one will take effect. All valid egress object name: port, vlan, vlanxlate, vfi, l3intf, mimlookupid, l2gre, vxlan, l3nat, niv, wlan, mim.

enhanced_ser_correction_event_report
Type:
number
Default:
0

This soc property is used to enable enhanced SER correction event report mechanism (i.e. parity correction/ECC 1-bit correction/ECC 2-bit correction event are identified). 0 => Use the traditional SER correction event report mechanism: Report event with SOC_SWITCH_EVENT_DATA_ERROR_CORRECTED type for both parity and ECC error correction(including 1-bit and 2-bit). 1 => Use enhanced SER correction event report mechanism: Report event with SOC_SWITCH_EVENT_DATA_ERROR_ECC_1BIT_CORRECTED type for ECC 1-bit error correction. Report event with SOC_SWITCH_EVENT_DATA_ERROR_ECC_2BIT_CORRECTED type for ECC 2-bit error correction. Report event with SOC_SWITCH_EVENT_DATA_ERROR_PARITY_CORRECTED type for parity error correction.

failover_fixed_nh_offset_enable
Type:
number

Enable Tomahawk3-like L3/MPLS failover (protection switching) with fixed next hop offset from primary NH on EGR_L3_NEXT_HOP table. Set value 1 to enabled the feature and half of EGR_L3_NEXT_HOP is reserved for possible failover usage. Default value is 0 which disable the fixed next hop offset failover.

Map a chip to a family. This is used in order to map several chips which require similar soc properties to a family, and than use the family as the property suffix. E.g, map chip X and Y to family Z, and than one can define property.Z than will be recognized by both X and Y.

Specifies S-Channel method/engine used for SOC memory bulk operations soc_mem_bulk_XXX(). FIFO - S-Channel FIFO engine is SBUS master. PIO - S-Channel PIO engine is SBUS master.
