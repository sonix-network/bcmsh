PHY

Set/Display phy characteristics

PHY

PHY and SerDes access: read and write PHY registers, list the PHY of each port, and run SerDes diagnostics (PRBS, eye scans, per-lane state, FEC and BER statistics). On Trident 3 every front-panel port is a lane of a Falcon (25G) or Merlin (10G) SerDes core, managed through PortMod (see PortMod). An external PHY exists only if the platform has one.

Sub-command keywords must be typed in full, in any case: phy diag works, phy dia does not. If the first word is not a keyword, the command treats it as a port bitmap and reads or writes PHY registers (see Register access below).

The built-in help does not list phymod, TS/TimeSync, extlb, wr, rd_cp, rd_cp2 or mod, and describes diag only in prose; the shell accepts all of them.

Several sub-commands are meant for older or external PHYs (WarpCore eye margins, BCM8483x manufacturing tests, BCM8747 clocks, EEE, OAM, long-reach copper, PHY firmware). On Trident 3 SerDes ports they usually just return an SDK error.

Reading (info, register reads, dumpall, the get forms and the diag display sub-commands) does not change anything, but each register access shares the MDIO/SBUS bus with linkscan. Writes, PRBS, loopback and the control options change SerDes or PHY state behind SONiC; PRBS and loopback stop traffic on the port, and a bad register write may leave the link down until the port is re-initialised.

Warning

phy diag takes the selected ports out of linkscan while it runs and puts them back afterwards. If a phy diag sub-command fails on a bad option, the ports may stay out of linkscan, and SONiC then no longer sees their link changes. Check with ps and re-enable linkscan on the ports if needed.

Warning

phy firmware writes a firmware image into an external PHY’s non-volatile memory and can leave the PHY unusable.

phy diag <pbmp> <sub_cmd> [<sub_cmd_args>]

Run a SerDes or PHY diagnostic on each port of the bitmap. Most sub-commands accept unit=<n> (0 is the internal SerDes, 1 the first external PHY) and if=<sys|line> to pick the PHY and its side. The sub-command word must be typed in full; an unknown word prints Error: unrecognized PHY DIAG command: <word>. See the warning above about linkscan.

The built-in help shows only dsc, veye, heye_r, heye_l, loopback, prbs, prbsstat, fecstat, linkmon, mfg and berproj; the shell also accepts peek, poke, load_uc, veye_u, veye_d, pcs, reg, eyescan, state, feyescan and sw_an.

phy diag sub-commands

Sub-command

Arguments

Purpose

dsc

[<arg>] [unit=<n>] [if=<sys|line>]. The optional word is passed to the SerDes driver; the help example uses debug.

Per-lane state: signal detect, lock, equalizer, eye.

pcs

[<arg>] [unit=<n>] [if=<sys|line>]

PCS status.

prbs

set|get|clear [unit=<n>] [if=<sys|line>] [Polynomial=<p>] [Invert=<n>]. Polynomial is P7(0), P15(1), P23(2), P31(3), P9(4), P11(5), P58(6), P49(7), P20(8), P13(9) or P10(10).

PRBS generator and checker. set and clear stop traffic.

prbsstat

[STArt [Interval=<sec>] | STOp | Counters | Ber | CLear | ?]

Periodic PRBS error counting and BER. PRBS must already be running. start runs a background collector until stop.

fecstat

same as prbsstat. The counters are CORREC_RS_CW, UNCORREC_RS_CW, BITS_ERROR, RS_SYMBOL_ERR, CORREC_BASER and UNCORREC_BASER.

Periodic FEC counters and pre-FEC BER.

berproj

[unit=<n>] [if=<sys|line>] [hist_errcnt_threshold=<n>] [sample_time=<n>]

Post-FEC BER projection.

eyescan

type, vertical_max, vertical_min, horizontal_max, horizontal_min, sample_resolution, sample_time, counter, flags, lane, error_threshold, time_upper_bound, nof_threshold_links, unit, if, ber_scan_mode, timer_control, max_err_control

Eye scan. See also portmod eyescan.

feyescan

[unit=<n>] [if=<sys|line>] [lane=<n>]

Fast eye scan.

LoopBack

[unit=<n>] [InterFace=<sys|line>] mode=<remote|local|global|none>

Set PHY loopback. Stops normal traffic.

linkmon

set|get [unit=<n>] [if=<sys|line>] [lane=<n>] [mode=<0..8>]

PCS link monitor.

reg

[core0|core1|core2|mld] <aer> <reg> [<value>]

Read, or with a value write, a SerDes register.

peek, poke

fb=<n> lane=<n> / fb=<n> val=<n>

Internal SerDes register peek and poke. poke writes.

load_uc

crc=<n> debug=<n>

Reload SerDes microcode. Disrupts the link.

veye, veye_u, veye_d, heye_r, heye_l

live, BER, range, lane, time_upper_bound

WarpCore eye margins (not Trident 3 SerDes).

mfg, state

Test=<n> Data=<n> File=<file>

BCM8483x copper-PHY tests and state dumps (not Trident 3).

sw_an

none

Software auto-negotiation diagnostics; see SW_AN.

phy prbs <pbmp> <set | get | clear> [Mode=<hc | si>] [Polynomial=<p>] [LoopBack=<bool>]

PRBS through the PHY-control interface. Mode is si (SerDes) or hc. Polynomial accepts P7(0) to P58(6) only; the phy diag … prbs form also accepts 7 to 10. set and clear stop traffic on the port; get reports the checker state.

Unvalidated

drivshell> phy prbs xe0 set Mode=si Polynomial=3
phy control <pbmp> [RxTune [<value>] | Dump | <key>=<value> ...]

With only a bitmap, show the PHY-control values of each port. With <key>=<value> options, set them. Keys include WanMode, Preemphasis, DriverCurrent, PreDriverCurrent, EqualizerBoost, Interface, InterfaceMax, SwRxLos, Dfe, LpDfe, BrDfe, LT, Cl74, Cl91, Cl108 and several Macsec* keys. RxTune starts receive-equalizer tuning (Rx Equalization Tuning start). Setting values changes SerDes state behind SONiC.

phy int <pbmp> [<regnum> [<value>]]

Like Register access below, but on the internal (intermediate) PHY of each port instead of the outermost one.

Unvalidated

drivshell> phy int xe0

Register access: phy <pbmp> [<regnum> [<value> | <devad> [<value>]]]

With only a bitmap, print the standard registers of each port’s PHY. With a register number, read that register; with a value as well, write it, which changes PHY state. For clause-45 PHYs the second number is the device address.

               format.
