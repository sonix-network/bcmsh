Dump

Dump an address space or registers

Dump

Shortest form: d.

Dump memories (tables), registers or SDK software state by name. See Memories and registers for table names, views, pipes and the display options. The table, register and sw forms are read-only.

Warning

dump mw, mh, mb, dv and pkt read memory at an address inside the syncd process. A wrong address crashes syncd.

Grammar:

dump [File=<name>] [Append=true|false] [raw] [hex] [all] [chg] [pipe0|pipe1]
     [nocache] [idx_phy] [nocheck_mem_mode]
     <TABLE>[.<COPY>] [<INDEX> [<COUNT>]] [<FIELD> ...]
dump <REGTYPE> ...           (SOC, PCIC, PCIM, MCS, IPROC, PHY, MW, MH, MB)
dump socmem [diff] [ext] [simpl]
dump format <format_name> [<value>]
dump sw <module>
dump sa | dv <address> | pkt <address> [<len>]

File= writes the output to a file in the syncd container instead of the console (it fails if file logging is already on). The flags must be typed in full (any case). Without an index the whole table is dumped. Field names after the table limit the output to those fields. On Trident 3 only pipe0 and pipe1 are valid. An unknown name prints Unknown option or memory to dump (use 'help dump' for more info).

Each table entry is printed on one line as <TABLE>.<block>[<index>]: <FIELD=value,...>; with chg, only the changed fields appear, and a table with nothing changed prints nothing. Aliases are accepted, but the output uses the table’s own name: dump raw all VLAN_TAB 1 1 prints VLAN.ipipe0[1]: ….

The built-in help also shows -filter <FIELD>=<VALUE>. The shell does not support it: the word is taken as a field name to display, so nothing useful is printed. Use SEArch to find entries by field value.

drivshell> dump chg EGR_IP_TUNNEL
drivshell> dump chg EGR_DVP_ATTRIBUTE
EGR_DVP_ATTRIBUTE.epipe0[1]: <RESERVED=0x00000000000040000000000000000000000000,DVP_ATTR_POLICY_DATA=0x00000000000010000000,COMMON:DISABLE_VLAN_CHECK=1,>

The two examples above come from a switch without VXLAN tunnels: dump chg l2x finds a single static entry in VLAN 1, EGR_IP_TUNNEL has no changed entries and prints nothing, and EGR_DVP_ATTRIBUTE has one. With VXLAN configured, the learned remote MACs appear in l2x and the tunnel endpoints in EGR_IP_TUNNEL.

Dump SOC [ADDR | RVAL | DIFF]

Dump all internal registers: ADDR only their addresses, RVAL only reset values (neither reads the hardware), DIFF only registers that differ from their reset value. PCIC and PCIM [<start> [<count>]] dump PCI configuration space and CMIC registers in the same way.

Built-in help

Usages:
    DUMP [File=<name>] [Append=true|false] [raw] [hex] [all] [chg]
            <TABLE>[.<COPYNO>] [<INDEX>] [<COUNT>] [[field1]..[fieldN]]
            [-filter <FIELD>=<VALUE>[,...]]
          If raw is specified, show raw memory words instead of fields.
          If hex is specified, show hex data only (for Expect parsing).
          If all is specified, show even empty or invalid entries
          If chg is specified, show only fields changed from defaults
          If pipe_x is specified show data from pipe_x(chip has two pipes)
          If pipe_y is specified show data from pipe_y(chip has two pipes)
          If pipe0 is specified show data from pipe0(chip has four pipes)
          If pipe1 is specified show data from pipe1(chip has four pipes)
          If pipe2 is specified show data from pipe2(chip has four pipes)
          If pipe3 is specified show data from pipe3(chip has four pipes)
          If pipe4 is specified show data from pipe4(chip has four pipes)
          If pipe5 is specified show data from pipe5(chip has four pipes)
          If pipe6 is specified show data from pipe6(chip has four pipes)
          If pipe7 is specified show data from pipe7(chip has four pipes)
          If nocache is specified, show data from h/w tables, skip cache
          If nocheck_mem_mode is specified, checking of unique_global mode, slice_mode will be skipped
          (Use "listmem" command to show a list of valid tables)
    DUMP PCIC                     (PCI config space)
    DUMP PCIM [<START> [<COUNT>]] (CMIC PCI registers)
    DUMP MCS <START> [<COUNT>] (MicroController Subsystem)
          For both Registers and Memories, (32 bits).
    DUMP SOC [ADDR | RVAL | DIFF] (All SOC registers)
          ADDR shows only addresses, doesn't actually load.
          RVAL shows reset defaults, doesn't actually load.
          DIFF shows only regs not equal to their reset defaults.
    DUMP SOCMEM [DIFF] [EXT] (All SOC memories)
          DIFF shows only memories not equal to their reset defaults.
          EXT Extended Dump - also shows mmu memories
    DUMP MW [<START> [<COUNT>]]   (System memory, 32 bits)
    DUMP MH [<START> [<COUNT>]]   (System memory, 16 bits)
    DUMP MB [<START> [<COUNT>]]   (System memory, 8 bits)
    DUMP SA                       (ARL shadow table)
    DUMP DV ADDR                  (DMA vector)
    DUMP PHY [<PHYID>]            See also, the 'PHY' command.
    DUMP FORMAT [<name> <value>]  Display the format fields and values.
