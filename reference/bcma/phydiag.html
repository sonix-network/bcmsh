PHYDiag

A command of the separate bcma command line; see Commands for other chip families.

PHY based diagnostics commands.

PHYDiag <port-range> dsc <dsc_option>
<port-range> prbs set Polynomial=<pval> [Invert=true|1|false|0]\
                      [dir=tx|rx|tx,rx] [lane=<lane-range>]
<port-range> prbs get|clear [lane=<lane-range>]
<port-range> pattern get|set  [lane=<lane-range>]
             mode=[OFF|JP03B|LINEAR|CUSTOM]
             custom_length=<140-240 in increment of 20>
             custom_pattern[0..7]=<pattern word>.
<port> eyescan type=fast|1|berproj|4 [lane=<lane-range>]
             [ber_scan_mode] [timer_control] [max_err_control]
             [sample_time] [horizontal_max] [horizontal_min]
             [vertical_max] [vertical_min]
<port-range> berproj HistogramErrorThreshold=<tval>\
                     SampleTime=<time>
<port-range> prbsstat\
             [STArt Interval=<seconds>|Counters|Ber|CLear|STOp]
<port-range> fecstat\
             [STArt Interval=<seconds>|Counters|Ber|CLear|STOp]
<port-range> linkcat mode=<tx|rx|lpbk|pre_rx|rx_measure|xt_rx|\
             xt_lptx|xt_agg|xt_f_agg|50G_nrz|25Gnrz|auto>\
             lane=<lane-range> \
             [pthread_max=<max_num_threads>]\
             [amp_scale=<amplitude_scale, 0 for default>]
<port-range> fdrstat [STArt bin_group=[low|high|both] \
             Interval=<seconds>] [Counters] [CLear] [STop]
<port-range> deskew <val>
<port-range> nr_er_lmt_bias set bias=<val> [osr=<val>]\
                                 [lane=<lane_range>]
<port-range> nr_er_lmt_bias get [osr=<val>] [lane=<lane_range>]

Built-in help

The 'dsc' command displays diagnostics information.

The 'eyescan' command runs the eyescan process and display the result
when done.

The 'prbs' command performs various pseudo random binary sequence
(PRBS) functions according to the configuration parameters.

The 'berproj' command projects the bit error rate (BER). It requires
PRBS to be running and being locked.

The 'prbsstat' command periodically collects PRBS error counters and
computes the BER based on the port configuration and the observed
error counters.
The 'prbsstat' command assumes that PRBS is already running on
the ports that PRBSstat will monitor.

The 'pattern'  command configure the PHY Tx Pattern.

The 'fecstat' command periodically collects forward error correction
(FEC) status counters such as corrected and uncorrected FEC codewords,
symbol error and bits error for a given port.
The command then uses bits error count to compute the pre-FEC BER for the
port, and uses symbols error count to compute the symbol error rate (SER)
for each lane of the port.

The 'linkcat' command runs channel analysis tool to collect data
on links.
The 'fdrstat' Flight Data Recodes (FDR) command periodically collects FEC
stats, and accumulates them every internal time.
The 'deskew' Command display the Rx Deskew information.
stats, and accumulates them every internal time.
The 'nr_er_lmt_bias' command set/get programmable offset to the NR/ER
decision threshold per OSR mode during link training.

PHY diagnostics command input:
<port-range>: Logical port number range, 1-3, port 1 to port 3.
              Logical port number list 1,2,3, port 1, 2 and 3.
lane=<lane-range>: Logical lane index range on the port, starting with
                   0. If the 'prbs set' command specifies lane range,
                   then the 'prbs get' and 'prbs clear' commands
                   should specify lane range as well.
HistogramErrorThreshold=<tval>: Histogram error threshold range is
                                3-7. Use 0 for auto mode.
SampleTime=<time>: Timeout value for the PRBS errors are accumulated.
bin_group: Indicates fdr error conters start S0-S7(low), S8-S15(high),
           or S0-S15(both).
dsc_option: lite|ber|config|cl72|debug|std|state|state_eye|state_lane            |state_lane_core

Built-in examples

1 dsc config
1-3 prbs set p=3 lane=0,1
1,2,3 prbs get lane=0,1
1,2,3 prbs clear lane=0,1
1 eyescan type=1
1,2 prbsstat start interval=60
1,2 prbsstat counters
1,2 prbsstat ber
1,2 prbsstat stop
1,2 pattern set mode=CUSTOM lane=0,1 custom_length=140  custom_pattern0=0x11110000
1,2 fecstat start interval=60
1,2 fecstat counters
1,2 fecstat ber
1,2 fecstat stop
1-3 linkcat mode=lpbk lane=0,1
1-32 linkcat mode=lpbk lane=0,1 pthread_max=0 amp_scale=25
1,2 fdrstat start bin_group=low interval=10
1,2 fdrstat stop1   deskew
1,2 nr_er_lmt_bias set bias=3 osr=1 lane=0-7
1,2 nr_er_lmt_bias get osr=1 lane=0,1
