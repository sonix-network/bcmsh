pktdev

A command of the separate bcma command line; see Commands for other chip families.

Manage packet device.

pktdev [<resource>] <action> [<id>] [options]

Built-in help

This command performs operations on a packet device or a packet device
resource.
    ATtach [options] - Attach a device driver.
        Type=<value>        - Device driver type.
    DeTach [options] - Detach device driver.
        CleanUp=[yes/no]    - Cleanup the packet device. Default is yes.
    Init [options] - Init a packet device.
        Name=<value>        - Device name string.
        DefPath=[yes/no]    - Create default path to enable TX/RX.
        MACaddr=<value>     - Network interface MAC address.
        CHGrp=<value>       - Channel group valid bitmap.
        FrameSize=<value>   - Default path's Max frame size.
        PipeId=<value>      - Pipe ID for TX/RX.
    Up           - Bring up device and default network interface.
    Down         - Pull down device and default network interface.
    CleanUp      - Cleanup the packet device.
    InFo         - Show the packet device status.
    Stats
        Show     - Show the packet device's statistics.
        Clear    - Clear the packet device's statistics.
    Chan
        Set <id> [options] - Configure a DMA channel.
            Dir=<value>      - Direction, TX or RX.
            PipeId=<value>   - Pipe ID for TX/RX.
            RingSize=<value> - DMA Channel ring size.
            FrameSize=<value>- Maximum frame size allowed.
        QueueMap <id> [options] - Map queues to a RX channel.
            HighWord=<value> - High 32 bits queue bitmap.
            LowWord=<value>  - Low 32 bits queue bitmap.
        Info [<id>] - Show a DMA channel's configuration.
    BufPool
        Create [options]  - Create a buffer pool.
            BufSize=<value> - Each buffer size.
            BufCount=<value>- Number of buffers.
        Destroy    - Destroy a buffer pool.
        CleanUp    - Cleanup all buffer pools.
        Info [All] - Dump buffer pool information.
    PacketPool
        Create [options]  - Create packet pool.
            PacketCount=<value>- Number of packets.
        Destroy    - Destroy packet pool.
        Info       - Dump packet pool information.
    RateLimit
        Set        - Set RX rate limit.
            RxRate=<value>  - RX Rate limit value in KPPS.
                              If -1, disable RX rate limit.
        Info       - Show RX rate limit configuration.
    SUSpend [options] - Suspend packet device.
        Graceful=[yes/no] - Gracefully suspend. Default is yes.
    RESume       - Resume packet device.

Built-in examples

init
i n="bcm1" defpath=yes
chan set 0 dir=TX ringsize=32
chan qm 1 hw=0xffff lw=0xfffffff
