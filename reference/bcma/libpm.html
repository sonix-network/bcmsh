LibPm

A command of the separate bcma command line; see Commands for other chip families.

FlowTracker debug command.

LibPm <object> [options]

Built-in help

The LIB_PM monitors both the AC and DC components of the silicon by
automatically measuring and storing ring oscillator frequencies and
DC IV characteristics. FullIV curves of MOSFETS, on-chip resistances,
parasitic R and C of metal lines, device aging, and device leakage
can be measured using the LIB_PM.
Objects:
    Write [options]     - Write data into a LIBPM register.
        Address=<value>    - LIBPM register address.
        Instance=<value>   - LIBPM instance (default -1 means all).
        Data=<value>       - 32 bits configuration data (default 0).
    Read [options]      - Read data from a LIBPM register.
        Address=<value>    - LIBPM register address.
        Instance=<value>   - LIBPM instance (default -1 means all).
    ReadRange [options] - Read data from a set of LIBPM registers.
        AddressStart=<value> - LIBPM register range first address.
        AddressEnd=<value> - LIBPM register range last address.
        Instance=<value>   - LIBPM instance (default -1 means all).
    Config [options]    - LIBPM global config.
        Clock=<value>      - Reference clock (Khz, default 25000Khz).
        VDNdefault=<value> - Default vdn (default 500ms).
        VDSdefault=<value> - Default vdn (default 750ms).
        VGSdefault=<value> - Default vdn (default 750ms).
        VDSStep=<value>    - VDN curve test step (default 50ms).
        VGSdefault=<value> - VGS curve test step (default 50ms).
        Vreg=<value>       - VREG (default 950ms).
        Enable=<value>     - 1 - enable (default), 0 - disable.
        Instance=<value>   - LIBPM instance (default -1 means all).
    IVTrim <object> [options] - Dump IV_Trim configuration.
        Atb [options]   - Enable ATB output for VREF/IREF trim.
            Select=<value>   - 1 - ready_signal, 0 - data (default).
            Enable=<value>   - 1 - enable, 0 - disable (default).
            Instance=<value> - LIBPM instance (default -1 means all).
        VRef [options]  - VREF Trim.
            vTc=<value>      - Trim vtc value.
            vDc=<value>      - Trim vdc value.
            Instance=<value> - LIBPM instance (default -1 means all).
        IRef [options]  - IREF Trim.
            iTc=<value>      - Trim itc value.
            iDc=<value>      - Trim idc value.
            Instance=<value> - LIBPM instance (default -1 means all).
        Dump [options]  - Dump IV_Trim configuration.
            Instance=<value> - LIBPM instance (default -1 means all).
    ICID [options]      - Dump ICID data.
        Instance=<value>   - LIBPM instance (default -1 means all).
    RINGs [options]     - Dump all RINGS data.
        Instance=<value>   - LIBPM instance (default -1 means all).
    DevIV [options]     - Dump all Dev_IV data.
        Instance=<value>   - LIBPM instance (default -1 means all).
        allDevice=<value>  - 1 - test, 0 - not test.
        Metalrc=<value>    - 1 - test, 0 - not test.
        Leakage=<value>    - 1 - test, 0 - not test.
        Curve=<value>      - 1 - test, 0 - not test.
        All=<value>        - 1 - test all above, 0 - option ignored.
    All [options]       - Dump all types' data.
        Instance=<value>   - LIBPM instance (default -1 means all).
