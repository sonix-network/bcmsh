cmis

A command of the separate bcma command line; see Commands for other chip families.

CMIS management user interface.

cmis <id> [lport=true] [NoneZero=true] <sub-cmd>

Built-in help

This command is used to manage CMIS on the Broadcom SVKs.
By default, <id> represents a Port Macro ID. Use 'lport=true'
to specify a logical port instead. Use 'NoneZero=true' to
show only non-zero values in dumps.

Info
    Show module's vendor and firmware information.
Status
    Show module's global operational status.
MONitors
    Show global monitors (e.g., temperature, voltage).
PageRead <bank> <page> [offset] [bytes]
    Dump CMIS memory page contents.
PageWrite <bank> <page> <offset> <data>
    Write a hex data string to a CMIS memory page.
ADvertising
    Show module's advertising capabilities.
APPDescriptors
    Show Application descriptors (supported interface technologies).
cdb [<cmd> [args]]
    Execute a CDB (Command Data Block) command. Use 'cdb' for list.
ClockMeasure [<ctrl> <value>]
    Show or set clocking and measurement controls.
DiagCapability
    Show diagnostics measurement capabilities.
DiagFlags
    Show diagnostics flags.
DiagMasks [<mask> [<val>|<LaneN=v>..]]
    Show or set masks for diagnostics flags.
DiagUserPATtern [<data>]
    Show or set the user pattern (up to 32 bytes).
FWLoad <file> [Commit=<0|1>] [LPL=<0|1>] [Retries=<n>] [Delay=<ms>]
    Upgrade module firmware from a binary file. This operation downloads
    the image, executes the Run command to activate it, and optionally
    executes the Commit command to make it permanent.
    Options:
      Commit  - Execute Commit command after successful Run (default: 0)
      LPL     - Use Local Payload (LPL) for download (default: 0)
      Retries - Max retry attempts (default: 3, range: 0-10)
      Delay   - Delay in ms before executing Run command (default: 500)
FWVersion
    Display current firmware version information.
LaneCtrl [<ctrl> [<LaneN=v>..]]
    Show or set lane-specific direct effect controls.
LaneDPInitCtrl [<ctrl> [<LaneN=v>..]]
    Show or set data path initialization controls for host lanes.
LaneDataPathState
    Show lane-associated data path states.
LaneDiag [OpticalPowerTxThreshold=<f>] [OpticalPowerRxThreshold=<f>]
          [LaserBiasTxThreshold=<f>] [HostSideSNRThreshold=<f>]
          [MediaSideSNRThreshold=<f>]
    Show lane diagnostics (optical power, bias, SNR). With thresholds,
    show only lanes below threshold. Use '-1' to scan all PMs (0-63).
LaneFlags
    Show lane-specific flags.
laneBER | laneERRors | laneSNR | laneGatedBER | laneGatedERRors
    Show various lane performance metrics.
LaneMask [<mask> [<LaneN=v>..]]
    Show or set masks for lane-specific flags.
LaneLoopBack [<cmd> [<LaneN=v>..]]
    Show or set Host/Media side loopback. Use 'capability' for info.
LaneActiveCtrlSet
    Show all lanes' active control set information.
LaneStagedCtrlSet <set> [<cmd> [<LaneN=v>..]]
    Show or configure a staged control set.
LaneStagedApply <set> [<cmd> [<LaneN=v>..]]
    Show or set an apply trigger on a staged control set.
LaneStagedResult
    Show the result from the last staged control apply.
LaneStatus
    Show lane-specific output status.
LaneMonitors
    Show media lane-specific monitors.
ModuleCtrl [<ctrl> <value>]
    Show or set module global controls (e.g., 'SoftwareReset 1').
ModuleMasks [<mask> <value>]
    Show or set masks for module global flags.
MonitorThresholds
    Show alarm and warning thresholds for all monitors.
PatternGenCheckCapability
    Show pattern generator and checker capabilities.
PatternGenCtrls [<ctrl> <value>]
    Show or set pattern generator controls.
PatternCheckCtrls [<ctrl> <value>]
    Show or set pattern checker controls.
