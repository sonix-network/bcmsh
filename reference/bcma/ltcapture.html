LtCAPture

A command of the separate bcma command line; see Commands for other chip families.

Capture of logical table operations.

LtCAPture start [LogFile=<file>] [WriteOnly=0|1]\
      [VerboseRealTime=0|1] [VerboseRealTimeLogFile=<file>]\
      [Raw=0|1]
stop
status
replay [LogFile=<file>[,<file2>,...<filen>]] [Timing=0|1]\
       [Verbose=0|1] [Submit=0|1] [OutputFile=<file>] [Raw=0|1]\
       [WriteOnly=0|1]
watch [<lt-match-string> ...] [MatchAction=None|BackTrace]
unwatch [<lt-match-string> ...]

Built-in help

This command will capture table operations invoked through the BCMLT
API and store them in a log file along with a time stamp.
The captured table operations can then be replayed later on demand.

If the 'VerboseRealTime' option is set to true, the captured data
will be displayed as CLI commands in real time. To capture the
CLI commands output in a file, use the 'VerboseRealTimeLogFile'
parameter.
In RealTimeVerbose mode the normal capture function can be disabled by
setting the 'LogFile' to "-".
Set 'Raw' parameter to 1 to set the captured CLI commands in a raw
staged output result.

To skip read operations such as 'lookup' and 'traverse' from
the capture, set the 'WriteOnly' option to true.

By default the replay is running in verbose mode without submitting
the table operations (dry run). The 'Submit' parameter must be
turned on for the replay to take effect.
The replay will be executed as fast as the system permits unless the
'Timing' parameter is set to true, in which case the replay function
will attempt to impose the original timing.
Set 'Raw' parameter to 1 to log the human readable replay to a raw
staged output result. This option will always be true when sumbit=1.
The 'WriteOnly' option can also be used in replay to skip the read
operations.

If a log file name is not specified, the name 'bcmlt.lcap' will be
used. If the 'OutputFile' parameter is set, the replay result
will be logged to the specified file name.

For a multiple units system, the 'start' command can be invoked
multiple times to capture the operations of different units to
different capture files. The 'replay' command can parse these capture
files separated by commas (,) through the 'LogFile' parameter to
replay the operations in a multiple units system.

Use "watch <lt-match-string> ..." command to set tables to be
watched during capture or replay. Omitting the <lt-match-string>
from the watch command will display the current status.
The 'MatchAction' option can be used to set the action for the watched
tables during capture. Default is 'None' for no action to perform.
The 'BackTrace' action will do backtrace dump for watched tables
entry operations. The match action will be reset to no action when all
tables are watched.
The "unwatch <lt-match-string> ..." command can be used to remove
watched tables which were added from the watch command. Omitting the
<lt-match-string> from the unwatch command will unwatch all currently
watched tables and return to the default status that all tables are
captured or replayed without filtering out.
