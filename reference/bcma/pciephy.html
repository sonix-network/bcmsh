PCIEphy

A command of the separate bcma command line; see Commands for other chip families.

PCIe diagnostics.

SetEpreg <addr> <value>

FwInfo

Built-in help

GetEpreg
   Display value of given PCIe core (endpoint) register.
SetEpreg
   Write given value into given PCIe core (endpoint) register.
Getreg [count [lane]]
   Display values start from given PCIe PHY (SerDes) register address.
   count - number of registers to be display.
   lane - Lane index for per lane registers.
Setreg [lane]
   Write given value into given PCIe PHY (SerDes) register.
   lane - Lane index for per lane register.
GetSubreg [count]
   Display values start from given PCIe subsystem register address.
   Use GetSubInfo command to share subsystem register map.
   count - number of registers to be display.
SetSubreg
   Write given value into given PCIe subsystem register.
   Use GetSubInfo command to share subsystem register map.
GetsubInfo
   Display PCIe subsystem register address map information.
   The PCIe subsystem can consist of some modules, e.g. PIEP, ANCIL.
PramRead
   Display PCIe PHY RAM content at given address.
   <size>: The number of 16-bit words to read.
Diag
   Display SerDes lane information.
   <lane_map>: The lane bitmap to diagnose.
               Bit 0 starts from the lane 0 of the first SerDes core.
   <diag_type>:
       dsc - Display core state and lane state.
       state - Display core state, all lanes state and event log.
       eyescan - Display eyescan for selected lane.
          [mode]: PCIe D5 serdes eyescan mode.
             fast - Fast eyescan resoultion.
             berproj - Do BER projection.
FwLoad
   Program contents of the given firmware file to QSPI flash.
FwCmp <file>
   Compare flash content with given file.
FwInfo
   Display firmware loading information.
