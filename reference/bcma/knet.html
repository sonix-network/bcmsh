knet

A command of the separate bcma command line; see Commands for other chip families.

KNET access.

knet <object> <action> [<id>] [options]

Built-in help

This command is used to manage KNET objects such as virtual network
interfaces and packet filters.
    Netif - Network interface operations.
        Create [options] - Create a new network interface.
            ID=<value>          - Netif ID (0 to automatically assign a ID).
            Name=<value>        - Netif name string.
            RcpuEncap=[yes/no]  - Enable RCPU header encapsulation.
            BindrxCHannel=[yes/no] - Bind RX Channel.
            BindtxPort=[yes/no] - Bind TX port.
            Vlan=<value>        - VLAN ID.
            MACaddr=<value>     - MAC address.
            Port=<value>        - Port number for TX binding.
            PortEncap=<value>   - The binding port's encapsulation type
                                  ("higig" | "higig2" | "ieee").
            Queue=<value>       - Output queue ID of the binding port.
            CHan=<value>        - Channel ID for RX Channel binding.
            FrameSize=<value>   - Maximum frame size allowed.
        Destroy <id>   - Destroy a network interface.
        Info [<id>]    - Show a network interface's configuration.
    Filter - Filter operations.
        Create [options] - Create a filter.
            DESC=<value>        - Filter's description.
            Priority=<value>    - Filter's priority.
            DestType=<type>     - Destination type to forward.
            DestID=<value>      - Destination ID to forward.
            DestProto=<value>   - Overwrite protocol.
            MirrorType=<value>  - Mirroring destination type.
            MirrorID=<value>    - Mirroring destination ID.
            MirrorProto=<value> - Overwrite protocol for mirror copy.
            StripTag=[yes/no]   - Enable to trip VLAN Tag.
            Vlan=<value>        - 16 bit TCI to match.
            IngressPort=<value> - Ingress port ID to match.
            SrcModePort=<value> - Source module port to match.
            SrcModeID=<value>   - Source module ID to match.
            Queue=<value>       - Source CPU port queue to match.
            CHan=<value>        - Source DMA Channel ID.
            FPRule=<value>      - FP rule number to match.
            Reason=<reason>     - Specific reason to match.
            RawData=<data>      - Raw data string to match.
            RawMask=<mask>      - Raw data mask string to match.
            MetaData=<mdata>    - Raw metadata with 32-bit values in
                                  words. See input format in the example.
            MetaDataMask=<mdata_mask> - Raw metadata mask to match.
        Destroy <id>   - Destroy a filter.
        Info [<id>]    - Show a filter configuration.

Built-in examples

netif create name="bcm0_1" mac=00:11:22:33:44:55 framesize=1518
n c n="bcm0_2" mac=00:01:02:03:04:05 fs=1518
filter create chan=1 priority=10 desttype=netif destid=1\
              ingressport=1
