MCSTimeStamp

Print MCS timestamp data

MCSTimeStamp

Shortest form: mcsts.

Show or configure the timestamp events that embedded firmware captures (used by time-synchronisation firmware such as BroadSync).

With no argument it prints every event; with an event number only that event. Each line shows the event number, the last and previous hardware timestamps, their difference, the equivalent TS1 value and the full time (<sec>.<nsec>). After the event number one keyword may follow (it can be abbreviated to its capital letters): ENable, DISable or CHanGe. CHanGe waits for the event’s timestamp to change before printing, and prints Timed out waiting for change in timestamp if it does not.

The display forms are read-only. ENable and DISable change what the firmware captures.

The table is only meaningful while time-synchronisation firmware runs on one of the embedded cores. The cores are in reset until an embedded application is loaded, and the SONiC image on the switches in this guide loads none (see Embedded applications). On such a switch mcstimestamp prints 19 events (0–18) whose values are leftover memory contents: random-looking timestamps and a full time of about 1.6 × 1019 seconds.

MCSTimeStamp ENable

Written MCSTimeStamp <event_id> ENable. Enable capture of one event.

Unvalidated

drivshell> mcstimestamp 3 enable
MCSTimeStamp DISable

Written MCSTimeStamp <event_id> DISable. Disable one event, unless the firmware itself uses it.

Unvalidated

drivshell> mcstimestamp 3 dis
MCSTimeStamp CHanGe

Written MCSTimeStamp <event_id> CHanGe. Wait for the event’s timestamp to change, then print it. Read-only.

Unvalidated

drivshell> mcstimestamp 3 chg

Built-in help

Parameters: [event_id] [ENable|DISable|CHanGe]
    Display or configure timestamps captured by UC
    event_id = timestamp event index.  If empty, all will print.
    ENable = enable the specified timestamp event
    DISable = disable specified timestamp event, unless used by firmware
    CHanGe = poll specified timestamp event for a change before displaying
