SHOW

Show information on a subsystem

SHOW

Show summary information about the switch and the SDK: counters, the port map, chip parameters, units, threads and several chip diagnostics. With no argument, show prints its help.

The first word picks what to show:

  • The keywords feature/features, soc_is/soc_is_chip, param/params, unit/units and sa/sarl must be typed in full (case does not matter).

  • Any other word is first tried as a memory (table) name; show <mem> describes that table.

  • Then it is matched against the topics Pci, Counters, Errors, Interrupts, Chips, Statistics, MIB, TeMPmonitor, MaterialProcess, RingOSC, PortMAP, Rate, Voltage, LinkPhyCounter, SubPortMap, ICID and Threads. They can be abbreviated (the capital letters are required). They are tried in this order, so show c means Counters, not Chips. An unknown word prints show: Error: Invalid option <word>.

The built-in help leaves out MIB, TeMPmonitor, MaterialProcess, RingOSC, PortMAP, Rate, Voltage, LinkPhyCounter, SubPortMap, soc_is and the counter flag MmuStatus. The shell accepts all of them.

Safety on a running switch

Topic

Effect

unit, param, features, soc_is, Chips, Errors, Interrupts, Threads, sa, <mem>, PortMAP, TeMPmonitor, Pci

Read-only.

Counters

Read-only for the switch. The shell remembers the last values it showed, and Changed/Same compare against them. Other users of show counters (for example techsupport basic) therefore change what you see as “changed”.

Statistics, MIB, Rate

Force a counter synchronisation from hardware. Counter values are not changed.

RingOSC

Writes the ring-oscillator control register to take a measurement. Diagnostic only; it does not affect forwarding.

show param [<chip>]

Dump the SDK’s device parameters: port blocks, port lists by type, table sizes. Useful to see which ports exist when configuring breakout by hand. With no argument it shows the current unit. A number between 0x5600 and 0x56ff or 0xb000 and 0xbfff is taken as a PCI device ID, and the parameters of that chip’s driver are shown. Read-only.

show counters [Changed] [Same] [Zero] [NonZero] [All] [Hex] [Raw] [ErDisc] [MmuStatus] [<reg>][.][<pbmp>]

Show packet counters.

  • Changed / Same: counters that changed, or did not change, since show counters last showed them.

  • Zero / NonZero (Z and NZ): select by value.

  • All: all four of the above.

  • Hex: print 64-bit hex values. Raw: print raw values without register names.

  • ErDisc: only error and discard counters.

  • MmuStatus: accepted, but not described in the built-in help.

The defaults are Changed and NonZero. The first word that is not a flag ends the flags. It is taken as a port bitmap, or as a counter register with an optional port (RPKT.xe0). A register that is not a counter prints Register is not a counter.

Each line is <COUNTER>[(<index>)].<port> : <value> +<change> [<rate>/s]: the counter’s current value, its change since the last show counters, and a per-second rate when it changed. (<index>) is the queue for per-queue counters such as MC_PERQ_PKT(4).cpu0.

SONiC’s show techsupport collects show counters (scripts/generate_dump (show techsupport collector)). FBOSS uses show count on Tomahawk-family switches (FBOSS: BcmSwitch gatherSdkState/rcload, validated shell commands, diag shell stress test, vendor-diag-shell skill, debugging doc). Read-only for the switch.

See also Troubleshooting queues and buffers for the queue and drop counters (PERQ_DROP_PKT_UC, DROP_PKT_ING, OBM_* …) and what each drop means.

show Pci

Probe and print PCI function 0 of every bus and device the syncd container can see. Read-only. From inside the SONiC syncd container the probe reads nothing: all 128 rows (busses 0–3, devices 0–31) show zeros, the switch ASIC included. Use lspci on the host, or dump pcic for the ASIC’s own PCI header (see Dump SOC).

Usages:
  show Pci        - Probe and display function 0 of all busses/devices
  show CHips      - Show all driver-supported device IDs
  show Counters [Changed] [Same] [Z] [NZ] [Hex] [Raw] [<reg>][.][<pbmp>]
    Display all counters, or only specified regs and/or ports
      Changed - include counters that changed
      Same    - include counters that did not change
      Z       - include counters that are zero
      Nz      - include counters that are not zero
      All     - same as: Changed Same Z Nz
      Hex     - display counters as 64-bit hex values
      Raw     - display raw 64-bit hex values, no register name(s)
      ErDisc  - Only show those counters marked with Error/Discard
    NOTES: If neither Changed or Same is specified, Change is used.
           If neither Z or Nz is specified, Nz is used.
           Use All to display counters regardless of value.
