KNETctrl

Manage kernel network functions

KNETctrl

Shortest form: knet.

Manage the KNET kernel network driver. KNET provides network interfaces (netifs: Linux netdevs such as SONiC’s EthernetN) and filters, which decide whether a packet sent to the CPU goes to a netif, to the user-space receive layer, or nowhere. See KNET and the CPU port.

The words netif, filter, debugpkt, create, destroy, show, on and off must be written in full (case does not matter), so knetctrl netif sh is rejected. The Key=<value> options of the two create forms can be abbreviated as usual.

The show forms are read-only. On SONiC, syncd creates and owns the netifs and filters, and it is not told about changes made here.

Warning

Destroying a netif or filter that syncd created cuts off the packets it carried, for example LACP, LLDP or BGP to the host. syncd can also run into errors later, when it tries to remove an object that is already gone. Creating a filter with a higher priority than SONiC’s can divert its packets.

knetctrl netif show

List the KNET network interfaces, one per line, or print <no network interfaces>. Each line reads Interface ID <id>: name=<name> type=<type> vlan=<vid> port=<port> and may end with the flags addtag, rcpu, keeprxtag and forcedid. type is Vlan, Port or Meta. port is the port name for Port netifs and n/a otherwise. Read-only. SONiC’s test suite uses this command (sonic-mgmt test suite files invoking bcmcmd (19 files)).

On a SONiC switch there is one Port netif per front-panel port, named after the SONiC interface (Ethernet0 on ce0, and so on), with vlan=0 and the keeprxtag flag. Interface IDs follow the port order of the SONiC configuration.

knetctrl netif create [Type=<type>] [Vlan=<vid>] [Port=<port>] [RCPU=<bool>] [AddTag=<bool>] [KeepRxTag=<bool>] [IFName=<name>] [CBData=<n>] [ID=<n>]

Create a KNET netif:

  • With Port=, packets sent on the netdev go straight out of that port.

  • With RCPU=yes, the netif carries meta-data.

  • Otherwise packets are injected into the switch pipeline in VLAN Vlan (default 1).

IFName names the Linux netdev, and ID asks for a specific netif ID. AddTag adds a VLAN tag before sending, and KeepRxTag keeps received tags. The shell also accepts Type=Vlan|Port|Meta, which is not in the built-in help; Port and RCPU take precedence over it. On failure the command prints Error creating network interface: <msg>. This changes KNET state.

Unvalidated

drivshell> knetctrl netif create Port=xe0 IFName=dbg0
knetctrl netif destroy <id>

Destroy netif <id> (take it from knetctrl netif show). The Linux netdev disappears with it. If the ID is not a number, the command prints its help. On failure it prints Error destroying network interface: <msg>. Other network operating systems use this command to tear down their own netifs (baseboxd knet_manager.cc).

Warning

Destroying a SONiC EthernetN netif breaks that port’s host packet path.

Unvalidated

drivshell> knetctrl netif destroy <id>
knetctrl filter show

List the KNET filters in match order, one per line, or print <no filters>. Each line starts Filter ID <id>: prio=<p> dest=<Null|NetIF|RxAPI|CallBack>(<dest_id>) desc='<desc>'. The match fields that are set follow, among them mirror=…, striptag, vlan=, vlanmask=, ingport=, srcmod=, srcport=, fprule=, cpucos=, MirrorSts=, reason=, reasonmask=, and the raw packet or out-of-band bytes (rawdata[<offset>]:0x…, OOBrawdata…). Read-only.

On a SONiC switch there is one filter per front-panel port, with priority 100, matching only ingport and delivering to that port’s netif (dest=NetIF(<n>) desc='EthernetN'). The list is in match order, not ID order: filters that were re-created later, for example when a port was reconfigured, appear at the end.

knetctrl filter create DestType=<Null | NetIF | RxAPI | CallBack> [DestID=<id>] [PRIOrity=<prio>] [DESCription=<str>] [StripTag=<bool>] [Mirror=<bool>] [MirrorID=<id>] [MirrorProto=<n>] [DestProto=<n>] [Vlan=<vid>] [VlanMask=<mask>] [IngPort=<port>] [SrcPort=<n>] [SrcModid=<n>] [Reason=<reason>] [ReasonMask=<reason>] [FPRule=<n>] [CpuCos=<cos>] [MirrorSts=<0|1>] [OobOffset=<n>] [OobByte0..3=<n>] [OobMask0..3=<n>] [PktOffset=<n>] [PktByte0..7=<n>] [CBData=<n>]

Create a KNET filter. DestType chooses where matching packets go:

  • NetIF: to the netif DestID.

  • RxAPI: to the user-space receive layer.

  • Null: dropped.

Priority 0 matches first. Reason and ReasonMask take CPU-reason names. PktByteN and OobByteN (with OobMaskN) match bytes at PktOffset in the packet or at OobOffset in its DMA metadata. An offset that is too large prints PktOffset too large - max is <n> (or the OobOffset equivalent). The shell also accepts DestType=CallBack, MirrorID and MirrorProto (a copy to a second netif), which the built-in help does not list. On failure the command prints Error creating packet filter: <msg>. This changes KNET state.

knetctrl filter destroy <id>

Destroy filter <id> (take it from knetctrl filter show). On failure the command prints Error destroying packet filter: <msg>.

Warning

Destroying a filter that SONiC created silently stops the packets it delivered, for example a trap’s packets to its EthernetN interface.

Unvalidated

drivshell> knetctrl filter destroy <id>
knetctrl debugpkt <on | off | show>

on makes KNET send one extra copy of every packet to the user-space receive layer, for debugging, and off stops the copies. show prints Knet debugging packet function is on! or … is off! and is read-only. Without an argument the command prints Requires string argument. While debug copies are on, every host packet is processed twice. It is off on a SONiC switch.

Hardware-validated

drivshell> knetctrl debugpkt show
Knet debugging packet function is off!

Built-in help

Usages:
  knetctrl netif create [Vlan=<vlan>] [Port=<port>] [RCPU=yes|no]
        Create a virtual network interface.
        Supported options:
          [AddTag=yes|no]      - Add tag before sending to switch port
          [KeepRxTag=yes|no]   - Keep tag of packets which are sent to this netif
          [IFName=<str>]       - Optional network device name
          [CBData=<val>]       - User data for knet rx cb
          [ID=<val>]           - Optional virtual network interface ID
  knetctrl netif destroy <id>
        Destroy a virtual network interface.
  knetctrl netif show
        Show virtual network interfaces.
  knetctrl filter create DestType=Null|NetIF|RxAPI [DestID=<id>] [options]
        Create a packet filter.
        DestID is required for DestType=NetIF only.
        Supported options:
          [DESCription=<str>]  - Optional filter description
          [PRIOrity=<prio>]    - Filter match order priority (0 is highest)
          [StripTag=yes|no]    - Strip VLAN tag before sending packet to NetIF
          [Mirror=yes|no]      - Copy packet to RxAPI (if DestType=NetIF)
          [DestProto=<proto>]  - Override default protocol (if DestType=NetIF)
          [Vlan=<vlan>]        - Match specified VLAN ID
          [VlanMask=<vlan>]    - Mask for vlan ID
          [IngPort=<port>]     - Match specified local ingress port
          [SrcPort=<port>]     - Match specified module port
          [SrcModid=<modid>]   - Match specified module ID
          [Reason=<reason>]    - Match specified reason for copy to CPU
          [ReasonMask=<reason>]- Mask to match copy to CPU reason
          [FPRule=<rule>]      - Match specified FP rule number (if FP match)
          [CpuCos=<cosq>]      - Match specified CPU COS
          [MirrorSts=<val>]    - Match on Mirror status
                                 1:mirrored copy 0:switched copy
          [OobOffset=<offet>]  - Match OOB data starting at this offset
          [OobByteX=<val>]     - Match OOB data byte X (X=[0..3] supported)
          [OobByte0=<val>]     - Match OOB data byte 0 (example)
          [OobMaskX=<val>]     - Match OOB mask byte X (X=[0..3] supported)
          [OobMask0=<val>]     - Match OOB mask byte 0 (example)
          [PktOffset=<offet>]  - Match packet data starting at this offset
          [PktByteX=<val>]     - Match packet data byte X (X=[0..7] supported)
          [PktByte0=<val>]     - Match packet data byte 0 (example)
          [CBData=<val>]       - User data for knet rx cb
  knetctrl filter destroy <id>
        Destroy a packet filter.
  knetctrl filter show
        Show all packet filters.
  knetctrl debugpkt [on|off|show]
        Enable/Disable debugging packet function.
        Once enabling this function, there will be one packet copy being
        sent/mirrored to RX API for debugging usage.
