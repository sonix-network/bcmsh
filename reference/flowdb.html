FlowDb

Flow Database for flexible tables

FlowDb

Shortest form: fd.

Browse the flow database: the description of the flexible (“flex flow”) tables that comes with the loaded CANCUN package. It lists the available flows and their handles, the options of each flow, the flow/function/option tuples, the memory views that implement them, and the logical fields of each flow. These are the names and numbers that the SDK’s flow API (used for VXLAN and other tunnels) works with.

Keywords are case-sensitive: type them in full and in lower case, exactly as shown. Only help may be in any case. Numbers may be decimal or 0x hex. A wrong or missing word makes the command fail without a message. help or no argument prints the usage.

The command exists only on devices with CANCUN flex flows. Elsewhere the shell reports it as not found. Trident 3 in SONiC has them, and all the display forms work.

The command is read-only.

FlowDb flow show

List the flows as a FLOW TABLE with columns flow_name and flow_handle. The list has the built-in flows first (CLASSIC_VXLAN 1, CLASSIC_L2GRE 2), then those defined by the CANCUN package, not sorted (GPE 21 to VXLAN_EVPN 36 with the CANCUN package of SONiC’s Trident 3 image).

Built-in help

Parameters: [flow_info|flow|flow_option|ffo|flow_logical_field|view|help] <args...>
  Flow DB database for flexible tables.
     flow_info show - Detailed per flow information.
     flow show  - Flow table, Displays available flows and associated flow handles.
     flow_option show - Flow option table, Displays avaiable options per flow
     ffo show - Flow function option tuple table

     ffo entry [<flow_id>] [<function_id>] [<option_id>
         - Display the associated view id for flow, function, option combination
     flow_logical_field show - Logical field table, displays logical fields per flow.
     view show - View table
     view entry [<view_id>] -
         - View information.
     view field entry [<view_id> <field_id>] -
         - Field information.
     help     - display this usage page.

  arguments for each operation:
