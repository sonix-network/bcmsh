Help

Print this list OR usage for a specific command

Help

Shortest form: h.

List commands with a one-line description each, or print the built-in usage of the named commands. Also reached as ??, and as ? with arguments. Read-only.

  • With no argument it lists the commands common to all modes, the commands of the current mode and the commands added at run time, one per line with a short description, then prints a summary of number formats (0x hex, decimal, leading 0 octal, 0b binary). Aliases and hidden commands are left out.

  • With command names it prints the usage text of each. For an alias it first prints Usage (NAME): is an alias for "TARGET". An unknown name prints Usage: Command not found: NAME and the command fails.

  • print-manual is described below.

help looks a name up among the current mode’s commands before the common ones. Where a mode command has a matching shortest form, you get its usage instead. help set shows setreg, for example; set ? shows the usage of the command that actually runs.

Nothing is printed at all if the configuration variable help_cli_enable is set to 0.

help print-manual

Print the description and full usage of every command, hidden ones included. This runs to several thousand lines; with bcmcmd give it a long -t. The keyword must be spelt out and be the only argument. It is not mentioned in the built-in help.

Hardware-validated

drivshell> help print-manual

Commands common to all modes:


COMMAND: ?        Description: Display list of commands

Parameters: None
  Display a complete list of commands in a concise format.


COMMAND: ??       Description: @help

Parameters: [command] ...
  Display usage information for the listed commands.
  If no parameters given, a list of all commands is printed with
  a short description of the purpose of the command.

Parameters: None

Parameters: [Unit #] ...

  an attempt is made to attached it.
