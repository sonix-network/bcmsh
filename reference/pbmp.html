PBMP

Convert port bitmap string to hex

PBMP

Parse a port bitmap (see Ports and port bitmaps) and print the resulting bitmap and port list. Use it to check how the shell interprets a port specification before passing it to another command.

The first word selects the form: bcm, disabled or port (case does not matter, but these words cannot be abbreviated). Anything else is parsed as a port bitmap, using the grammar in Port bitmap grammar. With no argument, pbmp lists every port bitmap the SDK keeps for the unit (all FE ports, all GE ports, all XE ports, and so on).

The built-in help describes an old chip (ports 1-29, fe0-fe23) and does not mention the bcm, disabled and port forms.

The 0x… number in the output is a bitmap of SDK logical port numbers: bit n is logical port n. It is not a SONiC or front-panel numbering.

pbmp is read-only in every form.

Hardware-validated

drivshell> pbmp xe0-xe5
PBMP: Invalid pbmp string (xe0-xe5); use 'pbmp ?' for more info.

Failed to execute the diagnostic command. Error: Operation failed.

Port names depend on the switch’s port configuration. The switch above has ce0–ce30 and xe0–xe4, so xe0-xe5 names a port that does not exist, and one bad port makes the whole string invalid. Use pbmp without arguments, or pbmp e, to see which ports exist.

Given a port bitmap, pbmp <pbmp> prints one line, <hex> ==> <port list>, where the port list names the ports with ranges and whole port types (ce,xe0-xe2,xe4). An invalid string prints PBMP: Invalid pbmp string (<s>); use 'pbmp ?' for more info., followed by the SAI front-end’s Failed to execute the diagnostic command. Error: Operation failed.

In the full no-argument listing of a SONiC Trident 3 switch with 100G and 10G ports, only XE, CE, E, GX, XL, CL, C, PORT, CMIC, LB, OVERSUB, MGMT and ALL are non-zero; FE, GE, HG and the other classes are empty. pbmp disabled shows every bitmap as zero when all ports are enabled.

pbmp port <port>

Resolve a single port name or number and print port <input> ==> <name> (<logical port>). Without a port it prints ERROR: missing port string. Read-only.

Hardware-validated

drivshell> pbmp port cpu0
    port cpu0 ==> cpu0 (0)
pbmp bcm [port <port> | <pbmp>]

Built-in help

Parameters: <pbmp>
    Converts a pbmp string into a hardware port bitmap.  A pbmp string
    is a single port, or a group of ports specified in a list using ','
    to separate them and '-' for ranges, e.g. 1-8,25,cpu.  Ports may be
    specified using the one-based port number (1-29) or port type and
    zero-based number (fe0-fe23,ge0-ge7).  'cpu' is the CPU port,
    'fe' is all FE ports, 'ge' is all GE ports, 'e' is all ethernet
    ports, 'all' is all ports, and 'none' is no ports (0x0).
    A '~' may be used to exclude port previously given (e.g. e,~fe19)
    Acceptable strings and values also depend on the chip being used.
    A pbmp may also be given as a raw hex (0x) number, e.g. 0xbffffff.
