STiMeout

Set S-Channel timeout in microseconds

STiMeout

Shortest form: stm.

Show or set how long S-channel operations may take before they time out, in microseconds. Without an argument it prints S-Channel timeout is <n> usec.

Setting it changes the timeout for every hardware access, including those of syncd. A value that is too small makes normal register and table accesses fail. The value is not checked.

Hardware-validated

drivshell> stimeout
S-Channel timeout is 300000 usec

Built-in help

Parameters: [usec]
    Sets number of microseconds before S-Channel operations time out.
    If argument is not given, displays the current setting.
