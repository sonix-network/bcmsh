Getreg

Get register

Getreg

Shortest form: g.

Read registers and print them with their fields decoded. A register can be given by name, by name with a port or index (CLMAC_CTRL.ce0, PROTOCOL_PKT_CONTROL[0]), or by address; see Memories and registers. Read-only, but reading a clear-on-read register (some counters and status registers) clears it.

Grammar:

getreg [raw] [hex] [chg] [<REGTYPE>] <REGISTER> [<FIELD> ...]

raw, hex and chg must be typed in full (any case). <REGTYPE> defaults to SOC (internal registers); PCIM reads CMIC registers by name or offset, and the other types (PCIC, IPROC, PHY, MW …) take an address. Field names after the register limit the output to those fields. Each register instance is printed as <NAME>.<block>[<instance>][<address>]=<value>: <FIELD=value,...>, for example RDBGC0_SELECT.ipipe0[1][0x86003d00]=0x800: <BITMAP=0x800>.

A name that is unknown, or not valid on this chip, prints Syntax error parsing "<name>" and the command fails. Not every register name from other Broadcom chips exists on a Trident 3: CMIC_DEV_REV_ID, for one, is rejected.

Getreg chg <REGISTER>

Print only the fields, and for multi-instance registers only the instances, whose value differs from the reset default. A quick way to see what the SDK configured.

Hardware-validated

drivshell> getreg chg TOP_PVTMON_RESULT_0
TOP_PVTMON_RESULT_0.top0[7][0x2004700]=0x2d62de: <PVT_DATA=0x2de,
   MIN_PVT_DATA=0x2d6>
Getreg raw <REGISTER>

Print the value without decoding fields. hex prints only the hex value, for scripts. The flags can be combined.

Hardware-validated

drivshell> getreg raw RDBGC0_SELECT
RDBGC0_SELECT.ipipe0[1][0x86003d00]=0x800
Getreg PCIM <cmic_register>

Read a CMIC register through the PCI memory window, by name (with or without the CMIC_ prefix) or by offset. An offset with no register name behind it is printed as cpu[(nil)] = <value>, without a name or field decode.

Hardware-validated

drivshell> getreg pcim 0x0
cpu[(nil)] = 0x5000

Output from the simulator

Values reflect the simulator, not real hardware.

Built-in help

Parameters: [hex|raw|chg] [<REGTYPE>] <REGISTER> [[field1]..[fieldN]]
    If <REGTYPE> is not specified, it defaults to "soc".
    <REGISTER> designates offset, address, or symbolic name.
    If hex is specified, dumps only a hex value (for Expect parsing).
    If raw is specified, no field decoding is done.
    If chg is specified, show only fields/regs changed from defaults.
    For a list of register types, use "dump".
