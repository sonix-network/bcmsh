Listreg

List register fields

Listreg

Shortest form: l.

List registers and show their fields. Read-only: it uses the chip description, not the hardware.

Grammar:

listreg [-alias] [-summary] <REGISTER> [<value>]
listreg -counters | -ed | -type

For <REGISTER>, an exact name prints its address, flags, and each field with its bit range and reset value; a number is taken as an address; anything else, or *, lists the registers whose names contain it (Unknown register; possible matches are:). The list is printed, but the command still counts as failed, so the SAI front-end adds Failed to execute the diagnostic command. Error: Operation failed. after it. A <value> after the register is decoded into its fields, without reading the hardware. A per-port register is shown under its first instance (CLMAC_CTRL.ce0) with every block that has a copy listed under Blocks:.

Options start with - and have one-letter forms: -a (-alias, show alias names), -s (-summary, one line per register), -c (-counters, list counter registers), -e (-ed, list error/discard counters) and -t (-type, list registers by block type). Without any argument it prints its usage. If the reglist_enable configuration property is 0 the command does nothing.
