L3

Note

This command belongs to the shell mode for newer (logical-table) switch chips and is not available on Trident 3.

Manage L3 (IP) addresses

Built-in help

Usages:
    l3 init    - Init L3 function.
    l3 detach  - Detach L3 function.

    l3 ing_intf add

    l3 ing_intf delete INTF=<val>
    l3 ing_intf get INTF=<val>
    l3 ing_intf clear
    l3 ing_intf show

       {ip=<val> | ip6=<val> | Mac=<val>} {masklen=<val> | MacMask=<val>}

       [DENse=<bool>] [AFR=<bool>]
           - vrf: -1 - OVERRIDE, -2 - GLOBAL; -4 - VRF_ALL.
    l3 route show [v6=<bool>] [start=<val>] [end=<val>]
       [DENse=<bool>] [AFR=<bool>]
    l3 route perf v4v6=<val> OPs=<val> [VRF_OPs=<val>] [loops=<val>]
                  [nsets=<val>] [DataMode=<val>] [UseApi=<bool>] [FORTE=<bool>]
                  [DENse=<bool>] [AFR=<bool>]
           - Test L3 route operation performance.
           - v4v6: 1 - IPv4; 2 - IPv6; 3 - IPv4 + IPv6; 4 - IPv6 + IPv4.
           - OPs: B0 - Add, B1 - Update, B2 - Lookup, B3 - Delete.
           - VRFs: B0 - VRF, B1 - GLOBAL, B2 - OVERRIDE.
                   Default: 3 for parallel, 1 for combined.
           - loops: Number of runs. Forced to 1 if no delete operation.
           - nsets: Number of sets.
           - DataMode: 1 - Reduced, 2 - Full.(for XFS only), 3 - 32 or 49 bits data
           - UseApi: 1 - Use BCM API.
           - FORTE: 1 - Use FORTE ALPM.
           - DENse: 1 - Add dense routes.
           - AFR: 1 - Add AFR routes.

           - v4v6: 0 - IPv4 + IPv6; 1 - IPv4; 2 - IPv6.
    l3 aacl perf v4v6=<val> OPs=<val> [loops=<val>]
                  [nsets=<val>] [UseApi=<bool>] [ip_src=<bool>]
           - Test L3 aacl operation performance.
           - v4v6: 1 - IPv4; 2 - IPv6; 3 - IPv4 + IPv6; 4 - IPv6 + IPv4.
           - OPs: B0 - Add, B1 - Update, B2 - Lookup, B3 - Delete.
           - loops: Number of runs. Forced to 1 if no delete operation.
           - nsets: Number of sets.
           - UseApi: 1 - Use BCM API.
           - ip_src: 0 - Destination address and dst L4 port.
                     1 - Source address and src L4 port.
