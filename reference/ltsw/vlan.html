VLAN

Note

This command belongs to the shell mode for newer (logical-table) switch chips and is not available on Trident 3.

Manage VLAN usage

Built-in help

Usages:
      vlan create <id> [PortBitMap=<pbmp> UntagBitMap=<pbmp>]
                                           - Create a VLAN
      vlan destroy <id>                    - Destroy a VLAN
      vlan clear                           - Destroy all VLANs
      vlan add <id> [PortBitMap=<pbmp> UntagBitMap=<pbmp>
                                           - Add port(s) to a VLAN
      vlan remove <id> [PortBitMap=<pbmp>] - Remove ports from a VLAN
      vlan show [Brief]                    - Display all VLANs
      vlan <id> <name>=<vlaue>             - Set per VLAN property
      vlan gport add <id> [PortID=<gport_id>
                                           - Add gport to a VLAN
      vlan gport delete <id> [PortID=<gport_id>
                                           - Delete gport from a VLAN
      vlan gport get <id> [PortID=<gport_id>
                                           - Check if gport belongs to a VLAN
      vlan gport clear <id>
                                           - Delete all ports from a VLAN
      vlan gport show <id>
                                           - Show all ports in a VLAN
      vlan control [<name> [<value>]]
                                           - Set/get VLAN-specific chip options
      vlan stat <id> Attach=<true|false> StatId=<sid>
                                           - Attach/detach a flex counter to a VLAN
      vlan default [<id>]                  - Show or set the default VLAN
      vlan translate [On|Off]              - Enable/disable Ing&Egr VLAN translation
      vlan port [<port>|all [<name> [<value>]]]
                                           - Set/get port-specific VLAN options
      vlan action port default add Port=<port> OuterVlan=<vlanid>
            InnerVlan=<vlanid> Prio=<prio> DtOuter=<action>
            DtOuterPrio=<action> DtInner=<action> DtInnerPrio=<action>
            OtOuter=<action> OtOuterPrio=<action> OtInner=<action>
            OtOuter=<action> ItOuter=<action> ItInner=<action>
            ItInnerPrio=<action> UtOuter=<action> UtInner=<action>
            ForwardingDomain=<fwd_domain> OuterTag=<action> InnerTag=<action>
            - Add port default VLAN tag with actions.
              Valid actions are { Add, Delete, Replace, None }
      vlan action port default get Port=<port>
            - Get port default VLAN tag actions
      vlan action translate add Port=<port> KeyType=<key>
            OldOuterVlan=<vlanid> OldInnerVlan=<vlanid> DtOuter=<action>
            OuterVlan=<vlanid> InnerVlan=<vlanid> Prio=<prio>
            DtOuter=<action> DtOuterPrio=<action> DtInner=<action>
            DtInnerPrio=<action> OtOuter=<action> OtOuterPrio=<action>
            OtInner=<action> OtOuter=<action> ItOuter=<action>
            ItInner=<action> ItInnerPrio=<action> UtOuter=<action>
            ForwardingDomain=<fwd_domain> OuterTag=<action> InnerTag=<action>
            - Add VLAN tag translation with actions.
              Valid actions are { Add, Delete, Replace, None }
              Valid key types are { Double, Outer, Inner, OuterTag,
              InnerTag, PortDouble, PortOuter, Policer,
              PortGroupDouble, PortGroupOuter, PortGroupInner}
      vlan action translate delete Port=<port> KeyType=<key>
            OldOuterVlan=<vlanid> OldInnerVlan=<vlanid>
            - Delete VLAN tag translation actions.
      vlan action translate get Port=<port> KeyType=<key>
            OldOuterVlan=<vlanid> OldInnerVlan=<vlanid>
            - Get VLAN tag translation actions.
      vlan action translate show
            - Show all VLAN tag translation actions.
      vlan action translate range add Port=<port>
            OuterVlanLo=<vlanid> OuterVlanHi=<vlanid>
            InnerVlanLo=<vlanid> InnerVlanHi=<vlanid>
            - Add VLAN tag range translation.
      vlan action translate range delete Port=<port>
            OuterVlanLo=<vlanid> OuterVlanHi=<vlanid>
            InnerVlanLo=<vlanid> InnerVlanHi=<vlanid>
            - Delete VLAN tag translation range.
      vlan action translate range clear
            - Delete all VLAN tag translation range.
      vlan action translate range show
            - Show all VLAN tag translation range.
      vlan action translate egress add PortClass=<class>
            OldOuterVlan=<vlanid> OldInnerVlan=<vlanid> DtOuter=<action>
            OuterVlan=<vlanid> InnerVlan=<vlanid> Prio=<prio>
            DtOuter=<action> DtOuterPrio=<action> DtInner=<action>
            DtInnerPrio=<action> OtOuter=<action> OtOuterPrio=<action>
            OtInner=<action> OtOuter=<action> ItOuter=<action>
            ItInner=<action> ItInnerPrio=<action> UtOuter=<action>
            UtInner=<action>
            ForwardingDomain=<fwd_domain> OuterTag=<action> InnerTag=<action>
            - Add VLAN tag egress translation with actions.
              Valid actions are { Add, Delete, Replace, None }
      vlan action translate egress delete PortClass=<class>
            OldOuterVlan=<vlanid> OldInnerVlan=<vlanid>
            - Delete VLAN tag egress translation actions.
      vlan action translate egress get PortClass=<class>
            OldOuterVlan=<vlanid> OldInnerVlan=<vlanid>
            - Get VLAN tag egress translation actions.
      vlan action translate egress show
