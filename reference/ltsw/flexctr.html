FlexCTR

Note

This command belongs to the shell mode for newer (logical-table) switch chips and is not available on Trident 3.

Manage flex counter

Shortest form: fctr.

Built-in help

Usages:
      flexctr quantization add <Object>=<Val> <NumRange>=<Val>
                               [<Val>-<Val>] [<Val>-<Val>] ...
                               - Create flexctr quantization
      flexctr quantization update <QuantId>=<Val>
                                  <Object>=<Val> <NumRange>=<Val>
                                  [<Val>=<Val>] [<Val>=<Val>] ...
                               - Update flexctr quantization
      flexctr quantization del [<QuantId>=<Val>]
                               - Delete flexctr quantization
      flexctr quantization show [<QuantId>=<Val>]
                               - Show flexctr quantizaiton
      flexctr index set <Object0>=<Val> <Object1>=<Val>
                        <BitNum0>=<Val> <BitNum1>=<Val>
                               - Setup action index for creation
      flexctr valueA set  <SELect>=<Val> <Type>=<Val>
                          [<Object0>=<Val>] [<Object1>=<Val>]
                               - Setup action value A for creation
      flexctr valueB set  <SELect>=<Val> <Type>=<Val>
                          [<Object0>=<Val>] [<Object1>=<Val>]
                               - Setup action value B for creation
      flexctr trigger set <Type>=<Val> [<SCale>=<Val>] [<Period>=<Val>]
                          [<Object>=<Val>] [<START>=<Val>] [<STOP>=<Val>]
                               - Setup action trigger for creation
      flexctr trigger update <StatId>=<Val> <Enable>=<true|false>
                               - Enable/Disable action trigger
      flexctr action add <Source>=<Val> <Hint>=<Val>
                         <Mode>=<Val> <Trigger>=<Val>
                               - Create flexctr action
      flexctr action del [<StatId>=<Val>]
                               - Delete flexctr action
      flexctr action show [<StatId>=<Val>]
                               - Show flexctr action
      flexctr stat show [Z/Nz] <StatId>=<Val> [<index0>-<index1>]
                               - Get flexctr stat
              Z  - show counters that are zero
              Nz - show counters that are not zero
      flexctr stat clear <StatId>=<Val> [<index0>-<index1>]
                               - Clear flexctr stat
      flexctr object show [<object>=<VaL>]
      flexctr sw_dump set [<level>=<VaL>]
      flexctr pool show [<Id>=<Val>] [<Stage>=<Val>] [<Pipe>=<Val>]
              - Show flexctr pool usage
              - Stage indicates flexctr stage, 0 for ingress, 1 for egress
              - Pipe indicates pipe ID, only valid in pipe mode
