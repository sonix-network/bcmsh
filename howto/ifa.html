In-band Flow Analyzer (IFA 2.0)

In-band Flow Analyzer (IFA) is in-band network telemetry: switches add a small record about themselves to sampled packets of a flow, so that the last switch, or a capture at the receiving host, sees the path a packet took, which ports it used and the TTL at each hop. IFA 2.0 is described in the IETF draft draft-kumar-ippm-ifa. A switch can play three roles:

  • the initiator picks packets of a flow, makes a copy (the probe), inserts an IFA header and its own metadata, and sends the probe along the same path as the original;

  • a transit node adds its own metadata to every IFA probe it forwards;

  • the terminator removes the IFA data and exports the collected metadata to a collector.

Trident 3 does the initiator and transit work in the pipeline: the IFA flow of the CANCUN package, a few switch controls, field processor entries and an internal loopback port. The terminator’s export runs as an embedded application on one of the chip’s R5 cores. SONiC images built from the community sources neither configure IFA nor ship the embedded application.

This page sets up an initiator and a transit node by hand with Cint, the way the Broadcom SAI does it, captures the probes at the receiving host, and shows the result in Wireshark. Download the captures and a Wireshark dissector to follow along:

  • ifa2-two-hops.pcap: probes with metadata from two switches

  • ifa2-one-hop.pcap: probes with metadata from the initiator only

  • ifa2.lua: Wireshark dissector for IFA 2.0 with the Trident 3 metadata format

Warning

Everything here changes the switch behind SONiC’s back: switch controls, flex flow tables, field processor entries, a mirror destination and port sampling. It is lost when syncd restarts, and SONiC knows nothing about it. Try it on a lab switch, and remove it again (see Removing it again).

ifa_init.c
/*
 * ifa_init.c - initialise the SDK IFA module against the loaded IFA2 app
 * and print its configuration.  Needs ifa_enable=1 (config add) and the
 * IFA2 firmware running on a uC (mcsload).
 * Run:  cint /root/ifa_init.c
 */
cint_reset();

int ii_main()
{
    int unit = 0;
    int rv;
    bcm_ifa_config_info_t cfg;

    rv = bcm_ifa_init(unit);
    printf("bcm_ifa_init: %d (%s)\n", rv, bcm_errmsg(rv));
    bcm_ifa_config_info_t_init(&cfg);
    rv = bcm_ifa_config_info_get(unit, &cfg);
    printf("bcm_ifa_config_info_get: %d (%s)\n", rv, bcm_errmsg(rv));
    if (rv == BCM_E_NONE) {
        print cfg;
    }
    return 0;
}

ii_main();
printf("DONE ifa_init\n");

Both calls answering Ok shows that the SDK and the application talk to each other. The transit node, sw4, ran without the application and without ifa_enable.

Recording the starting state

The setup below changes switch controls, the two internal loopback ports (65 and 131) and per-port controls. Print their values first, so that they can be put back afterwards:

ifa2_state.c
/*
 * ifa2_state.c - print the IFA 2.0 related switch state that
 * ifa2_node.c changes: switch controls, loopback ports, per-port controls,
 * sFlow mirror destinations and the IFA field group.  Read-only.
 * Set st_ports to the ports used with ifa2_node.c.
 * Run:  cint /root/ifa2_state.c
 */
cint_reset();

int st_ports[2] = {12, 115};
int st_nports = 2;
int st_group = 200;

int sc(char *name, bcm_switch_control_t t)
{
    int v = -1;
    int rv = bcm_switch_control_get(0, t, &v);
    printf("  %-34s %d%s\n", name, v, rv ? " (error)" : "");
    return 0;
}

int pc(int port, char *name, bcm_port_control_t t)
{
    int v = -1;
    int rv = bcm_port_control_get(0, port, t, &v);
    printf("  port %3d %-26s %d%s\n", port, name, v, rv ? " (error)" : "");
    return 0;
}

int st_main()
{
    int unit = 0, i, n = 0, rv;
    uint32 vm;
    bcm_gport_t gp;
    bcm_gport_t dest[4];
    int lb[2] = {65, 131};
    bcm_field_entry_t ents[16];

    printf("switch controls:\n");
    sc("IFA2Enable", bcmSwitchIFA2Enable);
    sc("IFA2HeaderType", bcmSwitchIFA2HeaderType);
    sc("IFA2MetaDataFirstLookupType", bcmSwitchIFA2MetaDataFirstLookupType);
    sc("IFA2MetaDataSecondLookupType", bcmSwitchIFA2MetaDataSecondLookupType);
    sc("IFAMetaDataAdaptTable", bcmSwitchIFAMetaDataAdaptTable);
    sc("IFA2OverLAG", bcmSwitchIFA2OverLAG);
    sc("IFA2TruncationHdrLenUpdate", bcmSwitchIFA2TruncationHdrLenUpdate);
    sc("SampleFlexRandomSeed", bcmSwitchSampleFlexRandomSeed);
    printf("loopback ports:\n");
    for (i = 0; i < 2; i++) {
        bcm_port_gport_get(unit, lb[i], &gp);
        pc(gp, "InternalLoopback", bcmPortControlInternalLoopback);
        vm = 0;
        bcm_port_vlan_member_get(unit, gp, &vm);
        printf("  port %3d vlan_member flags      0x%x\n", lb[i], vm);
    }
    printf("ports:\n");
    for (i = 0; i < st_nports; i++) {
        pc(st_ports[i] | 0x08000000, "PacketProcssingPort", bcmPortControlPacketProcssingPort);
        pc(st_ports[i], "SampleFlexRate", bcmPortControlSampleFlexRate);
        pc(st_ports[i], "SampleFlexDest", bcmPortControlSampleFlexDest);
    }
    rv = bcm_mirror_port_dest_get(unit, 0, BCM_MIRROR_PORT_INGRESS | BCM_MIRROR_PORT_SFLOW, 4, dest, &n);
    printf("sFlow ingress mirror destinations: %d (rv %d)\n", n, rv);
    for (i = 0; i < n; i++) {
        printf("  0x%x\n", dest[i]);
    }
    n = 0;
    rv = bcm_field_entry_multi_get(unit, st_group, 16, ents, &n);
    printf("field group %d: rv %d (%s), %d entries\n", st_group, rv, bcm_errmsg(rv), n);
    return 0;
}

st_main();
printf("DONE ifa2_state\n");

Setting up the initiator

ifa2_node.c makes the switch an initiator or a transit node. Set the variables at its top: the role, the device ID, the ports that should add metadata, and for the initiator the port and addresses of the flow.

ifa2_node.c
/*
 * ifa2_node.c - make this switch an IFA 2.0 initiator or transit node,
 * the way the Broadcom SAI does it on Trident 3, for one UDP flow.
 *
 * Set the variables at the top before running.  Every call prints its
 * return code.  This changes switch state behind SONiC's back; undo it
 * with ifa2_node_undo.c.
 *
 * Run:  cint /root/ifa2_node.c
 */
cint_reset();

int in_role       = 1;           /* 1 = initiator, 2 = transit */
int in_device_id  = 0x22222;     /* 20 bits, appears in the metadata */
int in_ifa_proto  = 253;         /* IP protocol that marks IFA packets */
int in_max_length = 255;         /* metadata stack limit, 4-byte words */
int in_max_hops   = 32;
int in_ports[2]   = {12, 115};   /* ports that add metadata on egress */
int in_nports     = 2;
int in_sample_port = 12;         /* initiator: port the flow arrives on */
bcm_ip_t in_sip = 0xC633640A;    /* initiator flow: 198.51.100.10 ... */
bcm_ip_t in_dip = 0xCB00710A;    /* ... to 203.0.113.10, UDP */
int in_group = 200;              /* IFP group created for IFA */

int ck(char *what, int rv)
{
    printf("%-44s %d (%s)\n", what, rv, bcm_errmsg(rv));
    return rv;
}

int field_id(bcm_flow_handle_t h, char *name)
{
    bcm_flow_field_id_t id;
    ck(name, bcm_flow_logical_field_id_get(0, h, name, &id));
    return id;
}

/* Switch controls and internal loopback ports (all roles). */
int in_switch()
{
    int unit = 0, i;
    int lb[2] = {65, 131};
    bcm_gport_t gp;

    ck("IFA2Enable=1", bcm_switch_control_set(unit, bcmSwitchIFA2Enable, 1));
    ck("IFA2HeaderType", bcm_switch_control_set(unit, bcmSwitchIFA2HeaderType, in_ifa_proto));
    ck("IFA2MetaDataFirstLookupType=0", bcm_switch_control_set(unit, bcmSwitchIFA2MetaDataFirstLookupType, 0));
    ck("IFA2MetaDataSecondLookupType=0", bcm_switch_control_set(unit, bcmSwitchIFA2MetaDataSecondLookupType, 0));
    ck("IFAMetaDataAdaptTable=0", bcm_switch_control_set(unit, bcmSwitchIFAMetaDataAdaptTable, 0));
    ck("IFA2OverLAG=1", bcm_switch_control_set(unit, bcmSwitchIFA2OverLAG, 1));
    ck("IFA2TruncationHdrLenUpdate=1", bcm_switch_control_set(unit, bcmSwitchIFA2TruncationHdrLenUpdate, 1));
    for (i = 0; i < 2; i++) {
        bcm_port_gport_get(unit, lb[i], &gp);
        ck("InternalLoopback=1", bcm_port_control_set(unit, gp, bcmPortControlInternalLoopback, 1));
        ck("vlan_member_set(0)", bcm_port_vlan_member_set(unit, gp, 0));
    }
    return 0;
}

/* Flex flow "IFA": header templates and per-port metadata (all roles). */
int in_flex()
{
    int unit = 0, i, speed, code;
    bcm_flow_handle_t h;
    bcm_flow_option_id_t opt;
    bcm_flow_match_config_t m;
    bcm_flow_encap_config_t e;
    bcm_flow_logical_field_t f[3];
    bcm_gport_t gp;

    ck("flow_handle_get IFA", bcm_flow_handle_get(unit, "IFA", &h));

    bcm_flow_option_id_get(unit, h, "LOOKUP_LOOPBACK_SUBTYPE_ASSIGN_DISABLE_VLAN_CHECK_ACTION", &opt);
    bcm_flow_match_config_t_init(&m);
    m.criteria = BCM_FLOW_MATCH_CRITERIA_FLEX;
    m.flow_handle = h;
    m.flow_option = opt;
    ck("flow_match_add loopback", bcm_flow_match_add(unit, &m, 0, NULL));

    /* IFA base header and metadata header for UDP (OPAQUE4 193). */
    bcm_flow_option_id_get(unit, h, "IFA_BASE_MD_HEADER_ASSIGN_LOOKUP", &opt);
    bcm_flow_encap_config_t_init(&e);
    e.criteria = BCM_FLOW_ENCAP_CRITERIA_FLEX;
    e.valid_elements = BCM_FLOW_ENCAP_FLEX_KEY_VALID | BCM_FLOW_ENCAP_FLEX_DATA_VALID;
    e.flow_handle = h;
    e.flow_option = opt;
    f[0].id = field_id(h, "DIRECT_ASSIGNMENT_10_ACTION_SET");
    f[0].value = 0x2F110000 | in_max_length;
    f[1].id = field_id(h, "DIRECT_ASSIGNMENT_11_ACTION_SET");
    f[1].value = 0xFFFF0000 | ((in_max_hops - 1) << 8);
    f[2].id = field_id(h, "OPAQUE4");
    f[2].value = 193;
    ck("flow_encap_add IFA header (UDP)", bcm_flow_encap_add(unit, &e, 3, f));

    /* Per-port metadata: device ID, name space, egress port speed. */
    bcm_flow_option_id_get(unit, h, "IFA_MD_LOOKUP_1_ADAPT1_SINGLE", &opt);
    for (i = 0; i < in_nports; i++) {
        ck("PacketProcssingPort", bcm_port_control_set(unit, in_ports[i] | 0x08000000,
                                   bcmPortControlPacketProcssingPort, in_ports[i]));
        bcm_port_speed_get(unit, in_ports[i], &speed);
        code = 0;
        if (speed == 25000)  { code = 1; }
        if (speed == 40000)  { code = 2; }
        if (speed == 50000)  { code = 3; }
        if (speed == 100000) { code = 4; }
        bcm_port_gport_get(unit, in_ports[i], &gp);
        bcm_flow_encap_config_t_init(&e);
        e.flow_port = gp;
        e.criteria = BCM_FLOW_ENCAP_CRITERIA_FLEX;
        e.valid_elements = BCM_FLOW_ENCAP_FLOW_PORT_VALID |
                           BCM_FLOW_ENCAP_FLEX_KEY_VALID | BCM_FLOW_ENCAP_FLEX_DATA_VALID;
        e.flow_handle = h;
        e.flow_option = opt;
        f[0].id = field_id(h, "DEVICE_ID");
        f[0].value = in_device_id & 0xFFFFF;
        f[1].id = field_id(h, "LNS");
        f[1].value = 1;
        f[2].id = field_id(h, "EGRESS_PORT_SPEED");
        f[2].value = code;
        printf("port %d speed %d code %d\n", in_ports[i], speed, code);
        ck("flow_encap_add port metadata", bcm_flow_encap_add(unit, &e, 3, f));
    }
    return 0;
}

/* IFP group with the qualifiers and actions IFA needs. */
int in_fp_group()
{
    bcm_field_group_config_t g;

    bcm_field_group_config_t_init(&g);
    g.flags = BCM_FIELD_GROUP_CREATE_WITH_ID | BCM_FIELD_GROUP_CREATE_WITH_ASET;
    g.group = in_group;
    g.priority = in_group;
    BCM_FIELD_QSET_INIT(&g.qset);
    BCM_FIELD_QSET_ADD(&g.qset, bcmFieldQualifyStageIngress);
    BCM_FIELD_QSET_ADD(&g.qset, bcmFieldQualifyIfaVersion2);
    BCM_FIELD_QSET_ADD(&g.qset, bcmFieldQualifySrcIp);
    BCM_FIELD_QSET_ADD(&g.qset, bcmFieldQualifyDstIp);
    BCM_FIELD_QSET_ADD(&g.qset, bcmFieldQualifyIpProtocol);
    BCM_FIELD_QSET_ADD(&g.qset, bcmFieldQualifySysHdrType);
    BCM_FIELD_QSET_ADD(&g.qset, bcmFieldQualifyPktType);
    BCM_FIELD_QSET_ADD(&g.qset, bcmFieldQualifyVlanFormat);
    BCM_FIELD_ASET_INIT(&g.aset);
    BCM_FIELD_ASET_ADD(&g.aset, bcmFieldActionLoopbackType);
    BCM_FIELD_ASET_ADD(&g.aset, bcmFieldActionIngSampleEnable);
    BCM_FIELD_ASET_ADD(&g.aset, bcmFieldActionHiGigClassSelect);
    BCM_FIELD_ASET_ADD(&g.aset, bcmFieldActionEgressClassSelect);
    BCM_FIELD_ASET_ADD(&g.aset, bcmFieldActionNewClassId);
    BCM_FIELD_ASET_ADD(&g.aset, bcmFieldActionEncapIfaMetadataHdr);
    BCM_FIELD_ASET_ADD(&g.aset, bcmFieldActionIntEncapEnable);
    BCM_FIELD_ASET_ADD(&g.aset, bcmFieldActionEgressFlowControlEnable);
    BCM_FIELD_ASET_ADD(&g.aset, bcmFieldActionEgressFlowEncapEnable);
    return ck("field_group_config_create", bcm_field_group_config_create(0, &g));
}

/* Initiator: mark the flow, sample it, and turn the copies into probes. */
int in_initiator()
{
    int unit = 0;
    bcm_mirror_destination_t d;
    bcm_gport_t gp;
    bcm_field_entry_t u, b, c0, c1;

    /* Sampled copies go to internal loopback port 65. */
    bcm_mirror_destination_t_init(&d);
    bcm_port_gport_get(unit, 65, &gp);
    d.gport = gp;
    d.truncate = 1;
    ck("mirror_destination_create", bcm_mirror_destination_create(unit, &d));
    printf("mirror_dest_id 0x%x\n", d.mirror_dest_id);
    ck("mirror_port_dest_add INGRESS|SFLOW",
       bcm_mirror_port_dest_add(unit, 0, BCM_MIRROR_PORT_INGRESS | BCM_MIRROR_PORT_SFLOW,
                                d.mirror_dest_id));

    /* First pass: the user's flow. */
    ck("entry_create flow", bcm_field_entry_create(unit, in_group, &u));
    bcm_field_qualify_SrcIp(unit, u, in_sip, 0xFFFFFFFF);
    bcm_field_qualify_DstIp(unit, u, in_dip, 0xFFFFFFFF);
    bcm_field_qualify_IpProtocol(unit, u, 17, 0xFF);
    ck("EgressFlowControl IfaHdrInsertionOverTrunk",
       bcm_field_action_add(unit, u, bcmFieldActionEgressFlowControlEnable,
                            bcmFieldEgressFlowControlIfaHdrInsertionOverTrunk, 0));
    ck("LoopbackType Masquerade",
       bcm_field_action_add(unit, u, bcmFieldActionLoopbackType, bcmFieldLoopbackTypeMasquerade, 0));
    ck("IngSampleEnable", bcm_field_action_add(unit, u, bcmFieldActionIngSampleEnable, 0, 0));
    ck("EncapIfaMetadataHdr 193", bcm_field_action_add(unit, u, bcmFieldActionEncapIfaMetadataHdr, 193, 0));
    ck("entry_install flow", bcm_field_entry_install(unit, u));
    printf("flow entry %d\n", u);

    /* Second pass: the looped-back copy becomes the IFA probe (UDP). */
    ck("entry_create second pass", bcm_field_entry_create(unit, in_group, &b));
    bcm_field_entry_prio_set(unit, b, 0x7FFFFFFF);
    bcm_field_qualify_SysHdrType(unit, b, bcmFieldSysHdrLoopbackCpuMasquerade);
    bcm_field_action_add(unit, b, bcmFieldActionHiGigClassSelect, 0, 0);
    bcm_field_action_add(unit, b, bcmFieldActionEgressClassSelect, 11, 0);
    bcm_field_action_add(unit, b, bcmFieldActionNewClassId, 0, 0);
    bcm_field_qualify_PktType(unit, b, bcmFieldPktTypeUdpIfa);
    bcm_field_action_add(unit, b, bcmFieldActionEgressFlowControlEnable,
                         bcmFieldEgressFlowControlIfaOverTrunkUdpUpdate, 0);
    bcm_field_entry_copy(unit, b, &c0);
    bcm_field_entry_copy(unit, b, &c1);
    bcm_field_qualify_VlanFormat(unit, b, 1, 3);
    bcm_field_action_add(unit, b, bcmFieldActionEgressFlowEncapEnable,
                         bcmFieldEgressFlowEncapIfaProbeInitOverTrunkStagWithUdpUpdate, 0);
    bcm_field_qualify_VlanFormat(unit, c0, 0, 3);
    bcm_field_action_add(unit, c0, bcmFieldActionEgressFlowEncapEnable,
                         bcmFieldEgressFlowEncapIfaProbeInitOverTrunkUntagWithUdpUpdate, 0);
    bcm_field_qualify_VlanFormat(unit, c1, 3, 3);
    bcm_field_action_add(unit, c1, bcmFieldActionEgressFlowEncapEnable,
                         bcmFieldEgressFlowEncapIfaProbeInitOverTrunkDtagWithUdpUpdate, 0);
    ck("entry_install second pass dtag", bcm_field_entry_install(unit, c1));
    ck("entry_install second pass stag", bcm_field_entry_install(unit, b));
    ck("entry_install second pass untag", bcm_field_entry_install(unit, c0));

    /* Sample every packet of the flow (rate 1) to the mirror. */
    ck("SampleFlexRandomSeed", bcm_switch_control_set(unit, bcmSwitchSampleFlexRandomSeed, 77803));
    ck("SampleFlexRate=1", bcm_port_control_set(unit, in_sample_port, bcmPortControlSampleFlexRate, 1));
    ck("SampleFlexDest=MIRROR", bcm_port_control_set(unit, in_sample_port, bcmPortControlSampleFlexDest,
                                                     BCM_PORT_CONTROL_SAMPLE_DEST_MIRROR));
    return 0;
}

/* Transit: add metadata to IFA 2.0 packets passing through. */
int in_transit()
{
    int unit = 0;
    bcm_field_entry_t t;

    ck("entry_create transit", bcm_field_entry_create(unit, in_group, &t));
    bcm_field_qualify_IfaVersion2(unit, t, 1, 0xFF);
    bcm_field_qualify_SysHdrType(unit, t, bcmFieldSysHdrNone);
    ck("IntEncapEnable", bcm_field_action_add(unit, t, bcmFieldActionIntEncapEnable, 0, 0));
    ck("entry_install transit", bcm_field_entry_install(unit, t));
    printf("transit entry %d\n", t);
    return 0;
}

in_switch();
in_flex();
in_fp_group();
if (in_role == 1) {
    in_initiator();
} else {
    in_transit();
}
printf("DONE ifa2_node\n");

What it does, for all roles:

  • turns on IFA 2.0 in the pipeline and sets the IP protocol number that marks IFA packets (bcmSwitchIFA2Enable, bcmSwitchIFA2HeaderType);

  • adds entries to the CANCUN IFA flow with the flow API: the IFA header and metadata header that the initiator inserts (version 2, local name space, maximum length 255 words, hop limit 31), and, for each port, the metadata this switch adds when a probe leaves through it (device ID, name space 1, port speed);

  • creates a field processor group with the qualifiers and actions IFA uses.

And for the initiator:

  • a mirror destination on internal loopback port 65 for sFlow-sampled packets, and sampling of every packet (rate 1) on the flow’s input port;

  • a field entry for the flow that samples the packet and marks it for IFA header insertion (EncapIfaMetadataHdr) on its second pass;

  • three second-pass entries that match the sampled copy coming back from the loopback port (untagged, single- and double-tagged) and turn it into a probe.

The original packet is forwarded unchanged; the probe follows it as a separate packet.

Time stamps

The SAI keeps the egress pipeline’s time of day in step with the chip’s time-stamp counter, every 500 ms. ifa2_tod_sync.c does this once:

ifa2_tod_sync.c
/*
 * ifa2_tod_sync.c - copy the timestamp counter into the egress-stage
 * time of day, as the SAI's IFA timer does every 500 ms.  IFA metadata
 * timestamps are only consistent after this.  Creates time interface 0
 * if there is none.
 * Run:  cint /root/ifa2_tod_sync.c
 */
cint_reset();

int ts_main()
{
    int unit = 0, rv;
    bcm_time_interface_t ti;
    bcm_time_ts_counter_t c;
    bcm_time_tod_t tod;
    uint64 secs, rem, tmp;

    bcm_time_interface_t_init(&ti);
    rv = bcm_time_interface_get(unit, &ti);
    printf("time_interface_get: %d (%s) flags 0x%x\n", rv, bcm_errmsg(rv), ti.flags);
    if (rv != BCM_E_NONE || !(ti.flags & BCM_TIME_ENABLE)) {
        bcm_time_interface_t_init(&ti);
        ti.flags = BCM_TIME_ENABLE | BCM_TIME_WITH_ID;
        rv = bcm_time_interface_add(unit, &ti);
        printf("time_interface_add: %d (%s)\n", rv, bcm_errmsg(rv));
    }

    sal_memset(&tod, 0, sizeof(tod));
    rv = bcm_time_tod_get(unit, BCM_TIME_STAGE_EGRESS, &tod);
    printf("egress tod before: %d (%s) %u s %u ns\n", rv, bcm_errmsg(rv), COMPILER_64_LO(&tod.ts.seconds), tod.ts.nanoseconds);

    sal_memset(&c, 0, sizeof(c));
    rv = bcm_time_ts_counter_get(unit, &c);
    printf("ts_counter_get: %d (%s) enable %d counter %d ns hi %u lo %u\n", rv, bcm_errmsg(rv),
           c.enable, c.ts_counter, COMPILER_64_HI(&c.ts_counter_ns), COMPILER_64_LO(&c.ts_counter_ns));

    sal_memset(&tod, 0, sizeof(tod));
    tod.time_format = c.time_format;
    COMPILER_64_COPY(&secs, c.ts_counter_ns);
    COMPILER_64_UDIV_32(&secs, 1000000000);
    COMPILER_64_COPY(&tmp, secs);
    COMPILER_64_UMUL_32(&tmp, 1000000000);
    COMPILER_64_COPY(&rem, c.ts_counter_ns);
    COMPILER_64_SUB_64(&rem, tmp);
    COMPILER_64_COPY(&tod.ts.seconds, secs);
    tod.ts.nanoseconds = COMPILER_64_LO(&rem);
    COMPILER_64_COPY(&tod.ts_adjustment_counter_ns, c.ts_counter_ns);
    rv = bcm_time_tod_set(unit, BCM_TIME_STAGE_EGRESS, &tod);
    printf("egress tod set: %d (%s)\n", rv, bcm_errmsg(rv));

    sal_memset(&tod, 0, sizeof(tod));
    rv = bcm_time_tod_get(unit, BCM_TIME_STAGE_EGRESS, &tod);
    printf("egress tod after: %d (%s) %u s %u ns\n", rv, bcm_errmsg(rv), COMPILER_64_LO(&tod.ts.seconds), tod.ts.nanoseconds);
    return 0;
}

ts_main();
printf("DONE ifa2_tod_sync\n");

Device ID, TTL, ports and port speed were correct for both hops in the captures. Removing it again

ifa2_node_undo.c removes the field group, the mirror destination and the flow entries, and puts back the values recorded at the start. Set its variables to the ports used and the values ifa2_state.c printed.

ifa2_node_undo.c
/*
 * ifa2_node_undo.c - remove what ifa2_node.c set up and put back the
 * values ifa2_state.c printed before.  Set the variables at the top to
 * the same ports and group as in ifa2_node.c, and the before-values.
 * Run:  cint /root/ifa2_node_undo.c
 */
cint_reset();

int un_ports[2]   = {12, 115};
int un_nports     = 2;
int un_sample_port = 12;
int un_group      = 200;
int un_seed       = 112224882;   /* SampleFlexRandomSeed before */
int un_adapt      = 1;           /* IFAMetaDataAdaptTable before */
uint32 un_lb_vlan = 0x2;         /* vlan_member flags of ports 65/131 before */

int ck(char *what, int rv)
{
    printf("%-44s %d (%s)\n", what, rv, bcm_errmsg(rv));
    return rv;
}

int un_main()
{
    int unit = 0, i, n = 0;
    int lb[2] = {65, 131};
    bcm_field_entry_t ents[16];
    bcm_gport_t dest[4];
    bcm_gport_t gp;
    bcm_flow_handle_t h;
    bcm_flow_option_id_t opt;
    bcm_flow_match_config_t m;
    bcm_flow_encap_config_t e;
    bcm_flow_logical_field_t f[1];
    bcm_flow_field_id_t id;

    /* Field entries and group. */
    bcm_field_entry_multi_get(unit, un_group, 16, ents, &n);
    for (i = 0; i < n; i++) {
        bcm_field_entry_remove(unit, ents[i]);
        ck("field_entry_destroy", bcm_field_entry_destroy(unit, ents[i]));
    }
    ck("field_group_destroy", bcm_field_group_destroy(unit, un_group));

    /* Sampling and the sFlow mirror destination. */
    ck("SampleFlexRate=0", bcm_port_control_set(unit, un_sample_port, bcmPortControlSampleFlexRate, 0));
    ck("SampleFlexDest=0", bcm_port_control_set(unit, un_sample_port, bcmPortControlSampleFlexDest, 0));
    ck("SampleFlexRandomSeed", bcm_switch_control_set(unit, bcmSwitchSampleFlexRandomSeed, un_seed));
    n = 0;
    bcm_mirror_port_dest_get(unit, 0, BCM_MIRROR_PORT_INGRESS | BCM_MIRROR_PORT_SFLOW, 4, dest, &n);
    for (i = 0; i < n; i++) {
        ck("mirror_port_dest_delete", bcm_mirror_port_dest_delete(unit, 0,
               BCM_MIRROR_PORT_INGRESS | BCM_MIRROR_PORT_SFLOW, dest[i]));
        ck("mirror_destination_destroy", bcm_mirror_destination_destroy(unit, dest[i]));
    }

    /* Flex flow entries. */
    bcm_flow_handle_get(unit, "IFA", &h);
    bcm_flow_option_id_get(unit, h, "IFA_MD_LOOKUP_1_ADAPT1_SINGLE", &opt);
    for (i = 0; i < un_nports; i++) {
        bcm_port_gport_get(unit, un_ports[i], &gp);
        bcm_flow_encap_config_t_init(&e);
        e.flow_port = gp;
        e.criteria = BCM_FLOW_ENCAP_CRITERIA_FLEX;
        e.valid_elements = BCM_FLOW_ENCAP_FLOW_PORT_VALID | BCM_FLOW_ENCAP_FLEX_KEY_VALID;
        e.flow_handle = h;
        e.flow_option = opt;
        ck("flow_encap_delete port metadata", bcm_flow_encap_delete(unit, &e, 0, NULL));
        ck("PacketProcssingPort=0", bcm_port_control_set(unit, un_ports[i] | 0x08000000,
                                     bcmPortControlPacketProcssingPort, 0));
    }
    bcm_flow_option_id_get(unit, h, "IFA_BASE_MD_HEADER_ASSIGN_LOOKUP", &opt);
    bcm_flow_encap_config_t_init(&e);
    e.criteria = BCM_FLOW_ENCAP_CRITERIA_FLEX;
    e.valid_elements = BCM_FLOW_ENCAP_FLEX_KEY_VALID;
    e.flow_handle = h;
    e.flow_option = opt;
    bcm_flow_logical_field_id_get(unit, h, "OPAQUE4", &id);
    f[0].id = id;
    f[0].value = 193;
    ck("flow_encap_delete IFA header (UDP)", bcm_flow_encap_delete(unit, &e, 1, f));
    bcm_flow_option_id_get(unit, h, "LOOKUP_LOOPBACK_SUBTYPE_ASSIGN_DISABLE_VLAN_CHECK_ACTION", &opt);
    bcm_flow_match_config_t_init(&m);
    m.criteria = BCM_FLOW_MATCH_CRITERIA_FLEX;
    m.flow_handle = h;
    m.flow_option = opt;
    ck("flow_match_delete loopback", bcm_flow_match_delete(unit, &m, 0, NULL));

    /* Loopback ports and switch controls. */
    for (i = 0; i < 2; i++) {
        bcm_port_gport_get(unit, lb[i], &gp);
        ck("vlan_member_set", bcm_port_vlan_member_set(unit, gp, un_lb_vlan));
    }
    ck("IFA2TruncationHdrLenUpdate=0", bcm_switch_control_set(unit, bcmSwitchIFA2TruncationHdrLenUpdate, 0));
    ck("IFA2OverLAG=0", bcm_switch_control_set(unit, bcmSwitchIFA2OverLAG, 0));
    ck("IFAMetaDataAdaptTable", bcm_switch_control_set(unit, bcmSwitchIFAMetaDataAdaptTable, un_adapt));
    ck("IFA2HeaderType=0", bcm_switch_control_set(unit, bcmSwitchIFA2HeaderType, 0));
    ck("IFA2Enable=0", bcm_switch_control_set(unit, bcmSwitchIFA2Enable, 0));
    return 0;
}

un_main();
printf("DONE ifa2_node_undo\n");

What is missing

This setup stops at the probe. A terminator would match IFA packets, copy them with their metadata to the IFA application on an R5 core (CPU queues 46 and 47), and the application would export the metadata as IPFIX to a collector (bcm_collector_create, an export template, bcm_ifa_collector_attach). TCP flows need a second header template (OPAQUE4 194, next header 6) and the TCP second-pass entries.
