bcmsh: the Broadcom diag shell

The Broadcom diag shell is the command interpreter built into the Broadcom switch SDK. On SONiC switches it is reached with bcmsh or bcmcmd and shows the prompt drivshell>. It gives direct access to the switch ASIC: port status, forwarding tables, registers, counters and the SDK API.

This guide describes the shell as shipped with SONiC for Trident 3 (BCM56870) switches. It covers how to reach the shell, the concepts its commands share, task-oriented how-tos, and a reference entry for every command, including those not listed by help.

New here? Start with Accessing the shell and Reading this guide, then look up commands in the Command reference or the Index.
