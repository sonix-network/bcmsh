Further reading

Other documentation about the Broadcom diag shell. Most of it describes other chips or other network operating systems that wrap the same shell (for example Cisco NX-OS bcm-shell, Cumulus Linux bcmcmd or SONiC bcmsh); the command syntax is largely shared, but output and available commands differ.
