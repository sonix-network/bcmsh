Callback types not in OpenBCM

Callback (function-pointer) types that the Cint interpreter on this build registers but that OpenBCM 6.5.27’s Cint does not, grouped by module. Back to Cint API on this build.

A Cint function with the same signature can be passed where such a type is expected (see The Cint language).
