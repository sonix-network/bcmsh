All registered functions

Every function the Cint interpreter on this build can call, with its prototype as Cint knows it, one page per module. Functions that are not in OpenBCM 6.5.27’s Cint are marked /* not in OpenBCM 6.5.27 */. Use the search box to find a function by name. Back to Cint API on this build.

Names in capitals are SDK macros that Cint registers as functions. Their parameters are shown as pointers, but you call them with plain variables as in C, for example BCM_GPORT_MODPORT_SET(gport, modid, port);.
