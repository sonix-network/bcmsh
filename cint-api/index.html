Cint API on this build

These pages list what the Cint interpreter on this build knows: every function, structure, enum, callback type and constant you can use from a Cint program. Names that are not part of the public OpenBCM 6.5.27 release are listed separately; for them there is no public header or example, so the prototype, structure layout or enum values shown here are the only reference. A few of them are declared in the OpenBCM headers but OpenBCM’s own Cint does not register them; those are marked /* declared in OpenBCM headers */.

See Looking up a function for other places to look up a function.
