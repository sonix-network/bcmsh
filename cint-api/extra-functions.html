Functions not in OpenBCM

Functions that the Cint interpreter on this build registers but that OpenBCM 6.5.27’s Cint does not, grouped by module. Back to Cint API on this build.

Names in capitals are SDK macros that Cint registers as functions. Their parameters are shown as pointers, but you call them with plain variables as in C, for example BCM_GPORT_MODPORT_SET(gport, modid, port);.
